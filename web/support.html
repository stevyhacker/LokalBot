Support

LokalBot is an open-source community project. Start with the fixes below; the GitHub issue tracker is the public support desk.

Common problems

Only my side of the call was recorded

LokalBot records the other side through macOS system-audio capture. Without that permission the app warns that the recording is microphone-only. Open System Settings → Privacy & Security → Screen & System Audio Recording, allow LokalBot to record system audio, then make a short test recording in the meeting app you use.

A meeting started but LokalBot did not ask to record

On a fresh install, LokalBot asks through a notification before it records a detected meeting, so allow its notifications in System Settings → Notifications. Browser meetings are detected through Accessibility, and calendar access helps match scheduled meetings. You can always start a recording yourself or switch to automatic recording in Settings.

A model download failed or stalled

Models download from Hugging Face or the publisher's host the first time you use them. Check your connection and free disk space (speech models range from about 0.7 GB to 3.2 GB), then retry from Settings → Models.

The transcript is in the wrong language or misses words

Try another speech model in Settings → Models. Qwen3-ASR 1.7B is the default and covers 52 languages and dialects; Whisper large-v3 turbo covers 99. The choice matters most on noisy or multilingual recordings.

Where is my data, and how do I remove it?

By default the library lives in ~/Library/Application Support/me.dotenv.LokalBot/: recordings, transcripts, summaries, the search index, downloaded models, and debug.log. Delete individual meetings in the app, or quit LokalBot and remove that folder to erase everything.

Does LokalBot run on an Intel Mac or macOS 14?

No. LokalBot needs Apple Silicon (M1 or later) and macOS 15.0 or later. See the system requirements.

Before opening an issue

Install the latest release, retry the smallest failing flow, and check the README.

Report a bug or request a feature

Open a GitHub issue

Include the LokalBot version, macOS version, Mac model and memory, the selected models, the exact action that failed, and reproducible steps. A redacted excerpt from debug.log can help.

Never post meeting audio, transcripts, screenshots, API keys, tokens, model-server credentials, or other private material.

Security reports

Do not disclose vulnerabilities in a public issue. Use GitHub's private vulnerability-reporting form. If it is unavailable, open a public issue with no exploit details and request a private contact channel.

Response expectations

Support is best-effort and response times are not guaranteed. Clear reproduction steps and a privacy-safe log excerpt make a response much more likely.
