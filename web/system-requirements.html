Compatibility

LokalBot system requirements

The short version: an Apple Silicon Mac on macOS 15 or later, a Windows 10 or 11 x64 PC (alpha), or an x86_64 Linux desktop with glibc 2.39 or later (alpha), plus enough disk for the models you choose.

Updated October 20, 2026 · 7 min read

Mac

  • Mac: Apple Silicon — M1 or later.
  • Operating system: macOS 15.0 or later.
  • Install: download the DMG, or run brew install --cask stevyhacker/tap/lokalbot.
  • Disk: room for the app, recordings, and selected models.
  • Internet: required for the initial app and model downloads; optional for the built-in workflow after setup.
  • Library: ~/Library/Application Support/me.dotenv.LokalBot.

Intel Macs are not supported. The Mac app is built around Apple Silicon acceleration, Core Audio process taps, the Neural Engine, MLX, and Metal. Windows and Linux have their own native app, built separately, with the same pages and the same library format.

How much memory does a Mac need?

The Mac app runs across the supported Apple Silicon range, but local language-model choice changes the practical memory requirement. Compact built-in models start around 0.53–1.28 GB. Several balanced summary and cotyping models recommend 16 GB of unified memory. The largest long-meeting models in the catalog are roughly 16.8–17.73 GB on disk and target Macs with 32 GB or more.

You do not need the largest model to record or transcribe a meeting. Choose a compact speech model and a smaller summarizer first, then move up only if the quality gain is worthwhile on your hardware.

Plan disk space on a Mac

  • Compact setup: a roughly 0.7 GB Qwen3-ASR speech model plus a small 0.53–1.28 GB language model.
  • Broader transcription: Whisper large-v3 turbo is roughly 1.6 GB; Qwen3-ASR 1.7B is roughly 3.2 GB.
  • Quality-focused summaries: larger catalog choices add about 5–18 GB each.
  • Meetings and day memory: audio, transcripts, and visual captures use additional space over time.

These numbers describe model downloads and may change when publishers update packaging. LokalBot lets you choose rather than downloading every model.

macOS permissions

Grant only the permissions for features you intend to use:

  • Microphone records your voice.
  • System audio / Screen Recording enables the selected meeting-app audio capture and visual screen context.
  • Calendar helps detect and title scheduled meetings.
  • Accessibility supports meeting detection, Cotyping, dictation insertion, and approved agent interaction.

On a fresh install, LokalBot asks through a notification before it records a detected meeting, and day tracking saves only app names and window titles. Visible text and encrypted screenshots are opt-in, gated by macOS permissions, and deleted after 14 days by default.

Windows (alpha)

  • Operating system: Windows 10 or 11 on an x64 PC.
  • Install: download the Windows installer from the latest release and run it. It installs LokalBot for your user into %LOCALAPPDATA%\Programs\LokalBot, with a Start menu shortcut and no administrator rights. It isn't code-signed yet, so SmartScreen asks first: choose More info → Run anyway. The release also has a portable zip.
  • System audio: WASAPI loopback records everything the computer plays, not just the meeting app.
  • Disk: about 4 GB for the default transcription, summary, and search models, plus your recordings.
  • GPU: optional. The built-in llama.cpp runs on a Vulkan GPU or on the CPU.
  • Library: %LOCALAPPDATA%\LokalBot.

Linux (alpha)

  • System: x86_64 with glibc 2.39 or later, such as Ubuntu 24.04, Debian 13, or Fedora 40 or newer.
  • Graphics: a Vulkan or OpenGL driver. Mesa is fine.
  • Audio: PulseAudio or PipeWire. LokalBot records the output monitor, so it captures everything the computer plays, not just the meeting app.
  • Install: download the Linux archive from the latest release, extract it, and run ./install.sh. It installs LokalBot to ~/.local/bin and adds it to your applications menu. The same release also has a .deb (Debian, Ubuntu), an .rpm (Fedora, openSUSE) and an Arch package. Installing the .deb, or the .rpm on Fedora, also adds the LokalBot repository, so sudo apt upgrade or sudo dnf upgrade brings later versions; with the Arch package, LokalBot tells you about updates instead of installing them.
  • Disk: about 4 GB for the default models, plus your recordings. The built-in llama.cpp runs on a Vulkan GPU or on the CPU.
  • GNOME: the tray icon needs the AppIndicator extension, and day memory needs the Window Calls extension.
  • Library: ~/.local/share/LokalBot.

Models on Windows and Linux

The Windows and Linux app has its own defaults:

  • Transcription: Qwen3-ASR 0.6B, with Parakeet v3, SenseVoice, and Whisper turbo as options.
  • Speakers: pyannote segmentation with TitaNet embeddings.
  • Autocomplete: LFM2.5 1.2B.
  • Summaries and search: Qwen3.5 4B and EmbeddingGemma 2, the same as on a Mac.
  • Screen text: accessibility (UI Automation on Windows, AT-SPI on Linux) plus on-device OCR, downloaded on request.

The benchmarks were measured on a Mac, so these engines have not been benchmarked yet.

Mac only for now

The Windows and Linux app has the same pages and reads the same library, but these features haven't been ported yet:

  • Selection actions (⌃⇧ W)
  • Meeting note export and daily memory notes for Obsidian and Logseq
  • Personal Context
  • Spoken summaries
  • Coding-agent sessions in day memory
  • Remember speakers (voice profiles)
  • Apple Intelligence
  • Granite Speech and GigaAM transcription

Before an important meeting

  1. Install the latest release and finish the selected model downloads.
  2. On a Mac, confirm the required macOS permissions in System Settings.
  3. Make a short recording in the actual meeting application.
  4. Play back both the microphone and system-audio tracks.
  5. Process the recording once, offline if offline use matters.

FAQ

Questions about this guide

Does LokalBot support Intel Macs?

No. Apple Silicon (M1 or later) is required.

Does it support macOS 14?

No. The minimum supported version is macOS 15.0.

Do I need 32 GB of memory?

No. Smaller models run on lower-memory Apple Silicon Macs and PCs. The 32 GB recommendation applies to the largest local language-model choices.

Does it run on Windows on ARM or ARM Linux?

No. The Windows and Linux versions are built only for x64 (x86_64) processors.

Can I move my library between a Mac and a PC?

Yes. The Mac, Windows, and Linux apps use the same library format, so a library recorded on one opens on the others. It lives in ~/Library/Application Support/me.dotenv.LokalBot on a Mac, %LOCALAPPDATA%\LokalBot on Windows, and ~/.local/share/LokalBot on Linux.
