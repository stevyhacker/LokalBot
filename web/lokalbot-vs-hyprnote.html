LokalBot vs Hyprnote

Hyprnote is the closest cousin on this list: open-source, local-first meeting notes — it helped prove the category. The app is now called anarlog, and hyprnote.com redirects to char.com, the team's newer product. The MIT-licensed anarlog app remains maintained, and it's good. Here's how LokalBot differs.

Verdict

Which one fits you?

Pick Hyprnote if…

A kindred project with different choices — all defensible.

  • You need the same notetaker on Windows or Linux
  • You already run Ollama or have LLM API keys you like
  • You want optional cloud sync and note sharing
  • You prefer the MIT license

Pick LokalBot if…

Local AI with the batteries included, and a wider brief.

  • You want zero setup: recommended models in-app, no keys, no separate LLM runner
  • You want meetings plus dictation, a day timeline, and autocomplete
  • Copyleft matters: GPLv3 keeps every fork's improvements open
  • You want transcripts, notes, and your screen activity searchable in one place

Questions

The short answers.

Aren't you basically the same project?

We overlap on the part that matters — local, bot-free meeting notes — and that's a good thing; the category needs more of it. We differ on scope (a workspace vs a notetaker), on shipped local AI vs bring-your-own model, on platforms, and on license.

What's Char?

The team's current product: an AI notepad in private beta at char.com, backed by Y Combinator. It's a separate codebase from the open-source anarlog app, which the team says remains maintained.

Why GPLv3 instead of MIT?

Copyleft. Anyone can fork LokalBot, but improvements have to stay open. For an app that hears your meetings and reads your screen, we want the audit path to survive every fork — the code you can read should always be the code you run.
