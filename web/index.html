A few questions.

What does it capture from my screen?

New installs start with activity-only tracking. You can turn tracking off, save visible text without pictures, or add encrypted screenshots. Text and screenshots are opt-in. Private windows, excluded apps and sites, and secure fields are skipped; use exclusions for anything you don't want retained. Captured text and screenshots are deleted after 14 days by default. Moments you explicitly save stay until you unsave or delete them.

Does anything leave my Mac?

Recordings and built-in processing stay local. Network access covers model downloads, update checks, and optional agent setup. A remote model receives the context needed for a request only after you approve its server. Approved agent commands can also access the network. Connected CLI or MCP tools have their own data handling; meeting and screen-memory access have separate permissions. See the privacy policy.

Can I choose my own models?

Yes. Start with the built-in local models, choose another downloaded model, or connect Ollama, Apple Intelligence, or an OpenAI-compatible server. Transcription, summaries, and autocomplete have their own model choices. See the transcription model guide and offline setup guide.

Is LokalBot free?

Yes. LokalBot is free and open source under GPLv3. There is no account, subscription, or LokalBot server. See the fact sheet for what it includes.

Which Macs does it run on?

Apple Silicon Macs (M1 or later) with macOS 15 or later. Intel Macs are not supported. Check the system requirements for memory and disk space.

Does a bot join my meetings?

No. LokalBot records your microphone and the meeting app's audio on separate tracks. Let participants know you're recording and get their consent. Read how recording works.
