The best open-source AI assistants you can run locally

Six private ChatGPT alternatives that run on your own computer, compared honestly: what each one is for, what it remembers about you, how it's licensed, and how to install it.

Updated November 9, 2026 · 12 min read

Disclosure: LokalBot is our app. To keep this fair, we installed the latest release of every app on November 9, 2026, took every screenshot ourselves, and checked each claim against the project's own site, docs, license, and release notes, listed at the end. Nobody paid to be included. We re-check the page every month; if something is wrong or out of date, tell us on GitHub.

The short answer

These six tools all run AI on your own computer, but they do different jobs. Pick by what you want to do:

  • A private ChatGPT-style chat app: Jan is open source and sets itself up in a few clicks. LM Studio is more polished, but its app is closed source.
  • Models for other apps, scripts, and coding agents: Ollama.
  • Answers from your documents: AnythingLLM.
  • One ChatGPT-like web app for your household or team: Open WebUI, running on top of Ollama. Read its license first if you plan to rebrand it.
  • An assistant that remembers your actual work, from meetings to what you saw on screen: LokalBot, our app.

They also work together. Most of them can use a model that Ollama or LM Studio is already serving, so you don't have to choose just one.

Which one is a ChatGPT alternative with memory?

ChatGPT can remember details you share and use them in later chats. Of these six, three remember something about you, and they do it in very different ways:

  • Open WebUI keeps memories under Settings → Personalization → Memory, marked Experimental. You can add them yourself, and with native tool calling the model can save them on its own. In our test with Qwen3.5 4B on Ollama, “Remember that I am vegetarian” got a friendly “I've noted that,” but nothing was saved. Memories we added by hand were used in the next chat. Its docs warn that memory works best with capable models.
  • AnythingLLM added Memories & Personalization in May 2026. It's off by default. Once you turn it on, a background job reads recent chats every three hours and keeps up to 5 memories about you plus 20 per workspace, which you can edit. It needs a model that supports tool calling.
  • LokalBot remembers your work rather than your chats: meeting transcripts, notes, and decisions, and, if you turn it on, what you saw on screen. Its Personal Context is an encrypted list of facts, preferences, and goals. It learns them overnight from your own words in meetings, never other speakers', or when you say “Remember …” in Ask. Every learned item shows the line it came from, and preferences wait for you to keep or dismiss them. Learning is on by default and one switch stops it.
  • Jan lists memory as coming soon. Its projects share instructions and files across chats today.
  • Ollama and LM Studio don't remember anything between chats.

Before you trust any assistant with memory, check what it saves, whether you can see and delete each item, and which model reads it. All of these keep memories on your own computer, but if you connect a cloud model, that model sees them too.

The six apps, one by one

In order from model runners to chat apps, with LokalBot last.

Ollama

The model runner other apps build on

With about 186,000 GitHub stars, Ollama is the best-known way to run open models on your own computer. One command downloads a model and runs it, and a local API that speaks the OpenAI and Anthropic formats serves it to other apps. That API is why so many tools in this list, LokalBot included, can use Ollama as their engine. On macOS and Windows it also has a simple chat app with chat history, file attachments, and a thinking switch. On Linux it is command line only.

Good for

  • Running models for other apps, scripts, and coding agents.
  • A dependable local API with one-command model downloads.

Watch out for

  • No memory between chats, and attached files are pasted into the prompt rather than indexed, so long files get cut off. Unless your GPU has 24 GB or more, the default context is 4,096 tokens.
  • Cloud models and web search are on by default, and using them needs an Ollama account. Set OLLAMA_NO_CLOUD=1 to turn them off.

LM Studio

The polished desktop app for trying models

LM Studio is a desktop app for finding, downloading, and running models from Hugging Face. It has a clean chat window, chat with documents, MCP tools, and a local server that speaks the OpenAI and Anthropic formats. It runs llama.cpp everywhere and Apple's MLX on Apple Silicon. Of the apps here, it's the nicest for trying and comparing models.

It is not open source. The app is proprietary, though free for home and work since July 2025. Its lms command-line tool, SDKs, and MLX engine are MIT-licensed. We include it because it's one of the most common answers to “how do I run AI locally?”

Good for

  • Trying and comparing models from Hugging Face.
  • Serving a model to other apps from a desktop app instead of the command line.

Watch out for

  • Closed source, and it remembers nothing between chats: its docs say the model only knows what's in the chat or the system prompt.
  • Document chat reads PDF, Word, and text files. Voice input and web search aren't in LM Studio; the company's new agent app, LM Studio Bionic, has them, partly on paid plans.
  • Intel Macs aren't supported.

Jan

The open-source ChatGPT-style desktop app

Jan is the open-source app that feels closest to ChatGPT: install it, let it download a recommended model, and start typing. It bundles llama.cpp, can also use cloud models with your own API keys, and has projects, chat with files with citations, MCP tools, web search, and an OpenAI-compatible local server. Analytics stay off unless you allow them during setup.

Good for

  • A simple, open-source private chat app.
  • Using local and cloud models side by side in one window.

Watch out for

  • No memory yet: Jan's site lists it as “coming soon”. Projects share instructions and files across chats in the meantime.
  • Web search is on by default and sends your query to Exa when the model decides to search. On Intel Macs, Jan only works with cloud models.
  • Jan published 11 security advisories on October 29, 2026, two of them critical. Use version 0.8.8 or later.

AnythingLLM

The app for chatting with your documents

AnythingLLM is built around workspaces of documents. Add PDFs, Word files, spreadsheets, web pages, or a GitHub repository, then ask questions and see the sources under each answer. It also has agents that browse the web and run scheduled jobs, MCP tools, voice input, and, in the desktop app for macOS and Windows, a meeting assistant that transcribes calls on your computer. The desktop app is single-user and has its own llama.cpp engine. The Docker version adds user accounts and an embeddable chat widget.

Good for

  • Asking questions across a pile of documents, with sources.
  • Small teams sharing document workspaces on one server.

Watch out for

  • Anonymous usage telemetry is on by default. Turn it off under Privacy, or with DISABLE_TELEMETRY=true on Docker.
  • Some desktop features, such as the meeting assistant and the Magic dictation and autocomplete tools, aren't in the public repository, and unlimited use of the Magic tools needs a paid Pro license.
  • Agent web search goes to You.com by default.

Open WebUI

The self-hosted ChatGPT for a household or team

Open WebUI is a self-hosted, ChatGPT-style web app. You run it as a server with Docker or Python, connect it to Ollama or any OpenAI-compatible API, and open it in a browser on any device, including as an installable app on your phone. It has the longest feature list here: accounts and groups, knowledge bases with citations, web search, memory, voice calls with local Whisper transcription, image generation, tools, and MCP.

Good for

  • One private ChatGPT-like web app for several people.
  • Power users who want every feature and don't mind running a server.

Watch out for

  • It doesn't run models itself; you need Ollama or another server beside it. A new desktop app (0.1.4, AGPLv3) can run both on one computer.
  • Since version 0.6.6 (April 2025) the Open WebUI License adds a branding clause to BSD-3 terms: above 50 users you may not remove the Open WebUI branding without an enterprise license. Its own docs say it is not an OSI-approved open-source license.
  • It's a server to keep updated: there were four releases between November 3 and 8, 2026, and security fixes ship often. With a small model, its built-in tools can pull answers off topic.

LokalBot

Our app: an assistant that remembers your work

LokalBot is our app, and it's a different kind of assistant. Instead of starting from an empty chat, it builds a memory of your work. It records meetings without a bot joining, transcribes and summarizes them on your computer, and, if you turn it on, keeps the text of what you saw on screen. Ask a question and the answer cites the meeting or screen moment it came from. It also has dictation, autocomplete in other apps, a search of folders you choose, and a read-only MCP server, off until you turn it on, so Claude Code or Codex can search your library. Its models are built in; you can also point it at Ollama or another OpenAI-compatible server.

Good for

  • Remembering what was said and decided in meetings, and finding something you saw.
  • Giving coding agents your context, read-only.

Watch out for

  • It isn't a general chat app for trying models; pair it with one of the apps above for that.
  • Recording needs your colleagues' consent, and screen memory and dictation need system permissions.
  • It's best on a Mac. The Windows and Linux app is in alpha, and LokalBot is a small project built by one developer.

Use them together

A common setup is one app that runs the model and another that you talk to:

  • Open WebUI and AnythingLLM both connect to Ollama out of the box, and to LM Studio's server as an OpenAI-compatible API.
  • Jan can add Ollama or LM Studio as a custom OpenAI-compatible provider.
  • LokalBot can use Ollama or any OpenAI-compatible server, such as LM Studio's or Jan's, in Settings → Models. A server on another computer has to be approved before it receives any of your context.

How we tested

On November 9, 2026, we installed the latest release of each app on a Linux test machine with an 8-core AMD Ryzen 7 9700X, 64 GB of memory, and no GPU, so every model ran on the CPU. LM Studio and Jan used the model each one suggests on first run: Gemma 4 E4B and Jan-v3.5-4B. Open WebUI and AnythingLLM used Qwen3.5 4B served by Ollama, as did Ollama itself. We kept each app's default settings, except that we declined Jan's analytics prompt and added two memories in Open WebUI by hand. In Open WebUI, the 4B model kept reaching for the built-in automation tools, and with thinking on it once thought for four minutes without answering, so the screenshot's chat uses Legacy tool calling with thinking off. LokalBot's screenshot comes from its Mac app with fictional demo data. The handbook and the questions are made up too.

A 4B model on a CPU is a modest setup: answers arrived at about 12 to 20 tokens a second. With a GPU or an Apple Silicon Mac, every one of these apps is faster and can run larger models, which also follow instructions and use memory more reliably.

FAQ

Questions about this guide

What is the best local AI assistant?

It depends on the job. For a private ChatGPT-style chat, Jan (open source) or LM Studio (more polished, but closed source). To run models for other apps and agents, Ollama. To ask questions across your documents, AnythingLLM. For one web app shared by a household or team, Open WebUI. For an assistant that remembers your meetings and what you saw on screen, LokalBot.

Which local AI assistant has memory like ChatGPT?

Open WebUI has a Memory feature, marked experimental, where you or the model can save facts about you. AnythingLLM has Memories, off by default, which it extracts from recent chats every three hours. LokalBot remembers your meetings and, if you turn it on, your screen, and learns facts and preferences from your own words. Ollama and LM Studio have no memory, and Jan lists it as coming soon.

Is LM Studio open source?

No. The LM Studio app is proprietary, though free for home and work since July 2025. Its lms command-line tool, its SDKs, and its MLX engine are open source under the MIT license.

Is Open WebUI still open source?

Its code is public, but since version 0.6.6 (April 2025) it uses the Open WebUI License, which adds a branding clause to BSD-3 terms. Its own documentation says it is not an OSI-approved open-source license. Code up to version 0.6.5 remains BSD-3.

Do I need a GPU to run a local AI assistant?

No. Our test machine had none, and a 4B model answered at about 12 to 20 tokens a second on an 8-core CPU, which is readable but not fast. A recent GPU or an Apple Silicon Mac is much faster and can run larger, more capable models.

Can these assistants work completely offline?

Yes, once the app and a model are downloaded, local chat works offline in all six. Some features use the network by default: Ollama's cloud models and web search, Jan's web search, AnythingLLM's anonymous telemetry, and update checks in most apps. Each app's section on this page says what to switch off.
