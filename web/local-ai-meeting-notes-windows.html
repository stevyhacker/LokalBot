Windows

Local AI meeting notes on Windows

LokalBot records both sides of a Teams, Zoom, or Meet call without a bot, transcribes and summarizes it with models on your PC, and keeps every meeting searchable. Here is what works on Windows and how to install it.

Updated October 26, 2026 · 5 min read

What works on Windows

LokalBot for Windows is a native app written in Rust with GPUI, the UI framework behind the Zed editor. It has the same pages as the Mac app and reads the same library format, so a library recorded on a Mac opens on Windows. It's an alpha.

  • Meetings without a bot. LokalBot records your microphone and your PC's audio through WASAPI loopback, so nothing joins the call. On Windows the second track is everything your PC plays, not one app. When it detects a meeting, it asks with a notification.
  • On-device transcription. Qwen3-ASR 0.6B by default, with Parakeet v3, SenseVoice, and Whisper turbo as options, and speakers separated with pyannote segmentation and TitaNet.
  • Notes and Ask. Summaries, decisions, action items, and answers with citations from Qwen3.5 4B in the built-in llama.cpp, Ollama, an OpenAI-compatible server you approve, or your ChatGPT or Claude plan.
  • Your day. App and window activity, and, if you turn it on, screen text and encrypted screenshots, read through UI Automation and on-device OCR.
  • Writing. Hold Alt+Space to dictate anywhere. Optional autocomplete suggests the next words in apps whose text fields support UI Automation, with LFM2.5 1.2B on your PC.
  • Calendar. Private iCal or CalDAV links from Outlook, Google, or another calendar name your recordings and list today's meetings.
  • Agents. A read-only CLI and MCP server for Claude Code, Codex, and other agents, and an optional Agent Mode that works on your files with your approval, in Git Bash or PowerShell.

Install without admin rights

Run LokalBot-<version>-windows-x86_64-setup.exe from the latest release. It installs for your user into %LOCALAPPDATA%\Programs\LokalBot, without administrator rights, and adds a Start menu shortcut and an Installed apps entry. Uninstalling keeps your library. A portable zip is in the same release.

The app isn't code-signed yet, so SmartScreen asks before the first launch: choose More info → Run anyway. Updates are signed: LokalBot checks for a new version once a day, verifies the download's signature, and installs it only when you choose Install and Relaunch. A winget package is in review.

Models and hardware

LokalBot needs Windows 10 or 11 on x64. On first launch it downloads the models you choose: about 4 GB for the default transcription, notes, and search models. llama.cpp runs on any Vulkan GPU, including AMD Radeon and Intel graphics, or on the CPU. On an NVIDIA GPU you can choose CUDA (experimental) in Settings → Models → llama.cpp; in testing on an NVIDIA L4, CUDA read a long prompt into Qwen3.5 4B 32% faster than Vulkan. See the system requirements.

What's not there yet

  • Code signing, so SmartScreen will warn until it's in place.
  • Selection actions, meeting note export and daily memory notes, Personal Context, spoken summaries, and coding-agent sessions in day memory are Mac only for now.
  • Bot-free is not consent-free. Tell the people in your meeting that you're recording, and follow the rules that apply to them.

FAQ

Questions about this guide

Why does Windows warn me before LokalBot opens?

The Windows build isn't code-signed yet, so SmartScreen asks first. Choose More info, then Run anyway. The source is public on GitHub, and every update LokalBot installs is checked against its signature first.

Does a bot join my Teams or Zoom calls?

No. LokalBot records your microphone and what your PC plays, on two tracks, so nothing joins the call and other participants don't see a notetaker. Tell them you're recording.

Do I need administrator rights?

No. The installer installs LokalBot for your user only. A portable zip that runs from any folder is also available.
