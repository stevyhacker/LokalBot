# Quick Whisper comparison

Compare the installed WhisperKit turbo model, full Whisper large-v3, and
TheStage's public Core ML encoder / MLX decoder on the same small local sample.
The 8 October 2026 results are in [the report](results/2026-10-08/REPORT.md).

This is a headless benchmark. It does not launch the app, change its selected
model, run UI tests, or write into the meeting library. Run models serially.
Only numeric aggregates belong in this directory; audio, references, model
outputs, and diagnostic logs belong in a private output directory.

## Sample and quality limits

`prepare.py OUT BCMS_MEETING_FOLDER ENGLISH_MEETING_FOLDER` selects two existing
speech segments per microphone/system track in each meeting. Eligible segments
last 10–25 seconds and contain at least 20 saved transcript words. It chooses
the one-third and two-thirds positions in chronological order, before candidate
inference. The recordings are converted to mono 16 kHz PCM without normalization.
The script also includes the existing synthetic `LiveTranscript` fixture.

The saved real-meeting text was generated by Qwen3-ASR. Word edit distance to it
measures **disagreement, not accuracy**; it cannot settle which model is right.
The synthetic fixture has a known script and permits a real word-error check.
Scoring lowercases, removes punctuation/control tokens and transliterates Serbian
Cyrillic to Latin while retaining diacritics. Script use is counted separately.

All clips use automatic language detection. BCMS clips also get a separate
Bosnian (`bs`) condition, following the earlier DualASR experiment. Do not mix
the conditions or count the same clip twice when calculating overall throughput.
Model loading and a five-second warm-up are excluded from decode timings.
Short excerpts do not establish long-meeting performance, battery life, language
coverage, or accuracy. First-load observations have different cache histories.

## Reproduction

Use the LokalBot CLI to resolve authorized meeting folders. Keep all private
inputs and outputs outside the checkout. Create the Python environment with uv
and the Apple extras from TheWhisper commit
`af7eebaa53154d7d1edd545274e4a2df5a855ace`; its runtime pins are Torch/torchaudio
2.7.0, transformers 4.52.3, MLX 0.25.2 and coremltools 8.3.0. Add `numpy<2`,
`rapidfuzz`, and `soundfile`. The dependency snapshot is saved with the results.

`download.py OUT` downloads only public model assets at the recorded revisions.
It has no audio inputs. The installed turbo model should be cloned into
`OUT/models/current-turbo` and verified against the app's pinned speech catalog.
Use its `.lokalbot-tokenizer` directory for both WhisperKit models.

Build the release harness with `swift build -c release --package-path harness`.
It pins WhisperKit 1.1.0. Optionally set `WHISPERKIT_SOURCE` to an existing local
checkout of that exact version and revision
`1e2a163736dfa5a198e637ae44c114e1c6d5cc2d`.

The executable accepts, in order: private clip manifest, model directory,
tokenizer directory, WhisperKit model name, private JSONL output, model label.
Use `large-v3-v20240930` / `current-turbo` for the installed model and
`large-v3` / `full-large-v3` for the full model.

`run_stage.py OUT` runs the free TheStage turbo S/10-second Apple assets.
It constructs the model skeleton from JSON on PyTorch's meta device, installs
the unchanged publisher Core ML/MLX encoder and decoder, and reads safetensors.
It never opens or executes the publisher's pickle skeleton. This adaptation
must be considered when interpreting compatibility failures; it is not a test
of the vendor's commercial Apple SDK. `--probe` selects an English meeting
clip and the synthetic control for a focused check of word timestamps.
`--segment-mode` reproduces the diagnostic run using boolean segment timestamps;
its output is separate from the final word-timestamp comparison.

Run inference with `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`, and
`HF_HUB_DISABLE_TELEMETRY=1`. The recorded run also used a macOS sandbox profile
containing `(version 1) (allow default) (deny network-outbound)`. Public model
downloads happen separately. `/usr/bin/time -l` records process RSS; it does
not measure total system/ANE/GPU memory.

`score.py OUT SUMMARY_JSON` writes aggregate metrics without transcript text.
Raw clips and results remain private. The 2026-10-08 run's private directory was
`/private/tmp/lokalbot-whisper-quick-eval-20261008`; temporary files may be cleared
by the operating system, so retain them elsewhere privately if needed.
