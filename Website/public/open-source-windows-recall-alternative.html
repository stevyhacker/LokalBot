Windows privacy

An open-source Windows Recall alternative that is opt-in and encrypted

Microsoft Recall requires a Copilot+ PC NPU, ships as closed-source OS plumbing, and raised lasting privacy concerns about always-on screen snapshots. LokalBot for Windows (alpha) offers an open-source (GPLv3), opt-in, encrypted alternative that runs on any Windows 10 or 11 x64 PC.

How LokalBot keeps screen memory bounded

  • Activity first, pixels opt-in: Fresh installs track only app names and window titles so you can build a workday timeline without storing a single pixel.
  • Separate consent for text vs screenshots: Enable visible text via Windows UI Automation and built-in Windows OCR without saving screenshots, or opt into AES-GCM encrypted screenshots with a 14-day default expiry.
  • Private windows and sensitive fields excluded: Private browser windows are skipped, and you can exclude any application (such as password managers or banking apps) in Settings.
  • No Microsoft account or telemetry: LokalBot installs per-user without administrator rights into %LOCALAPPDATA%\Programs\LokalBot and runs offline once models download.

What else comes in the same Rust + GPUI app

Unlike screen-only recorders, LokalBot pairs your day timeline with bot-free Teams, Zoom, and Google Meet recording (WASAPI process loopback on Windows 11), local transcription and summaries, push-to-talk dictation (Alt+Space), 56 ms local autocomplete, Obsidian Markdown export, and end-to-end encrypted sync with the iOS and Android companion apps over LAN or Tailscale. Read the full platform breakdown in Local AI meeting notes on Windows.

Honest alpha caveats on Windows

  • The Windows installer (setup.exe) and portable zip are not code-signed yet, so Windows SmartScreen asks before first launch (choose More info > Run anyway). Updates check cryptographic signatures before installing.
  • Windows on ARM is not supported yet; builds target x64 PCs.
  • A few Mac features (Nemotron diarization, Gmail briefs, Granite Speech) are still Mac-only.

FAQ

Questions about this guide

Do I need a Copilot+ PC or an NPU to run LokalBot on Windows?

No. LokalBot runs on any Windows 10 or 11 x64 machine using any Vulkan GPU (AMD, Intel, or NVIDIA), experimental CUDA on NVIDIA GPUs, or the CPU.

Does LokalBot take screenshots immediately after install?

No. Fresh installs record app and window activity only. Reading screen text and saving AES-GCM encrypted screenshots are explicit opt-in toggles in Settings.

How does LokalBot compare to Screenpipe on Windows?

Screenpipe records screen and audio continuously (~30 GB/mo) under a source-available commercial license. LokalBot starts activity-only, deletes captures after 14 days by default, ships built-in local summary models, and is free under GPLv3. See LokalBot vs Screenpipe.
