100% ローカル · GPLv3 · 日本語対応

Bot不要・クラウド送信ゼロのローカルAI議事録。

LokalBotは、macOS（Apple Silicon）およびWindows・Linux（アルファ版）向けの無料オープンソース（GPLv3）議事録・作業メモリアプリです。会議室にBotを入れずに自分のマイクと相手側の音声をローカル録音し、文字起こし・要約・検索・音声入力をすべて端末内で完結します。

更新日 2026年11月20日 · GPLv3 · macOS 15+ (Swift) · Windows & Linux アルファ (Rust + GPUI) · Android LAN E2E同期

Bot不要

Zoom・Teams・Meetを両側トラックでローカル録音

会議に外部Botを参加させず、自分のマイクと会議アプリの音声を別トラックで録音します。アカウント登録やテレメトリは一切ありません。※録音時は必ず参加者の同意を得てください。

日本語精度

Qwen3-ASR 1.7Bによるオンデバイス文字起こし

標準のQwen3-ASR 1.7Bは日本語FLEURS検証で6.5% CER（llama.cpp動作）を記録。Whisper large-v3 turboやParakeetにも切替可能で、日本語を含む24言語のUIとCJKフレーズ検索に対応しています。

Obsidian連携

YAMLプロパティ付きMarkdownを自動出力

要約・決定事項・アクション項目をタイムスタンプ付きでObsidian VaultやLogseqへ自動書き出し。手動で追記した内容は上書きせずに保持します。

音声入力・補完

ローカル音声入力と56 ms入力補完

⌥ Space（Mac）またはAlt+Space（Windows/Linux）の長押しでどのアプリでもローカル音声入力が可能。Gemma 4 E2B（中央値56 ms）による会議文脈を踏まえた入力補完も利用できます。

コーディング連携

Claude Code / Codex向け読み取り専用MCP

デフォルトはオフ。有効にすると、ローカルのClaude CodeやCodexから会議の決定事項を引用付きで検索でき、クラウドへ会議データを送らず実装へ繋げられます。

ネイティブ設計

Electron不使用（Swift + Rust/GPUI）

macOS版はネイティブSwift、Windows・Linux版（アルファ）はRust + GPUIで構築。AndroidコンパニオンアプリはLANまたはTailscale経由でエンドツーエンド暗号化同期に対応します。

FAQ

よくある質問

完全にオフラインでも動作しますか？

はい。初回のモデルダウンロードが完了すれば、Wi-Fiを切った状態でも録音・文字起こし・要約・検索・音声入力のすべてが動作します。

社内規定で会議Botが禁止されていても使えますか？

LokalBotは会議サービスにアカウント接続せず、参加者一覧にBotも表示されません。音声や議事録が外部クラウドに送信されないため、社内のセキュリティ確認もしやすくなります（録音前の参加者同意と社内規程の確認は必須です）。

Windows版とLinux版の現在のステータスは？

Windows（x64）およびLinux（.deb / .rpm / Arch / .tar.gz）はネイティブRust + GPUIのアルファ版として公開中で、Mac版と同一のローカルSQLite形式を扱えます。Windowsインストーラーは現在コード署名準備中です。

本当に無料ですか？将来の値上げはありませんか？

GNU GPLv3のオープンソースソフトウェアであり、アカウントも課金プランも存在しません。サーバー側で動作する機能がないため、サブスクリプション化される構造自体がありません。
