100% 로컬 · GPLv3 · v0.14.0 미세조정 모델

봇 없이, 클라우드 없이 내 컴퓨터에서 끝나는 AI 회의록.

LokalBot은 macOS(Apple Silicon), Windows, Linux(알파)를 위한 무료 오픈소스(GPLv3) 회의록 및 작업 메모리 앱입니다. v0.14.0부터 4종의 Apache-2.0 미세조정 로컬 모델을 기본 탑재해 계정이나 서버 전송 없이 녹음, 전사, 요약, 검색, 음성 입력을 기기 안에서 처리합니다.

업데이트 2026년 11월 26일 · v0.14.0 · GPLv3 · macOS 15+ · Windows & Linux 알파 (Rust + GPUI) · iOS & Android LAN E2E 동기화

봇 없는 녹음

Zoom·Teams·Meet 양쪽 오디오 로컬 분리 녹음

회의방에 외부 봇을 초대하지 않고 내 마이크와 회의 앱 오디오를 별도 트랙으로 녹음합니다. 계정과 텔레메트리가 전혀 없습니다. 녹음 전에는 반드시 참석자 동의를 구하세요.

한국어 지원

Qwen3-ASR v3 온디바이스 전사 & CJK 구문 검색

기본 탑재된 Qwen3-ASR 1.7B (LokalBot v3)는 한국어를 포함한 52개 언어 전사와 무음 환각 0건을 달성했습니다. 한국어 UI와 SQLite FTS5 기반 CJK 부분 문자열 검색을 기본 지원합니다.

Obsidian 연동

YAML 프론트매터 포함 Markdown 자동 저장

회의 종료 후 요약, 결정 사항, 할 일을 타임스탬프와 함께 Obsidian 또는 Logseq 폴더에 자동 저장하며, 사용자가 직접 수정한 노트는 덮어쓰지 않습니다.

음성 입력 & 보완

로컬 받아쓰기와 56 ms 자동완성

⌥ Space(Mac) 또는 Alt+Space(Windows/Linux)를 길게 눌러 어느 앱에서나 오프라인 음성 입력이 가능합니다. Gemma 4 E2B (LokalBot v4, 문맥 56/56 통과) 기반 자동완성도 제공합니다.

코딩 에이전트

Claude Code·Codex·Cursor용 읽기 전용 로컬 MCP

기본 비활성화 상태이며, 설정에서 켜면 Claude Code, Codex, Cursor, Windsurf, Gemini CLI, Antigravity가 로컬 stdio MCP로 회의 결정 사항을 출처와 함께 검색할 수 있습니다.

네이티브 앱

Electron 없이 Swift + Rust/GPUI

macOS는 네이티브 Swift, Windows·Linux(알파)는 Rust + GPUI로 제작되었습니다. iOS 및 Android 컴패니언 앱은 클라우드 서버 없이 LAN 또는 Tailscale로 종단간 암호화 동기화합니다.

FAQ

자주 묻는 질문

인터넷 없이 완전히 오프라인으로 동작하나요?

네. 최초 1회 오픈소스 모델을 다운로드한 뒤에는 비행기 모드에서도 녹음, 전사, 요약, 검색, 받아쓰기가 모두 동작합니다.

회사 보안 정책상 회의 봇이 금지되어 있어도 쓸 수 있나요?

LokalBot은 회의에 봇을 참여시키지 않으며 오디오와 텍스트를 외부 클라우드로 전송하지 않습니다. 다만 사내 녹음 규정 확인과 참석자 사전 동의는 반드시 필요합니다.

Windows와 Linux 버전은 어느 정도 완성되었나요?

Windows(x64)와 Linux(.deb, .rpm, Arch, .tar.gz)는 Rust + GPUI 네이티브 알파로 제공되며 Mac과 동일한 SQLite 라이브러리를 공유합니다. Windows 설치 프로그램은 코드 서명 준비 중입니다.

기존 Granola, Otter, Fireflies 기록을 가져올 수 있나요?

네. LokalBot 앱에서 직접 가져오거나, 서버 업로드 없는 브라우저 오프라인 변환기(/migrate)로 Obsidian 마크다운으로 변환할 수 있습니다.
