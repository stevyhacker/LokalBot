Локальные заметки встреч без облака и без ботов.

LokalBot — бесплатная open-source альтернатива Granola, Otter и Wispr Flow для macOS (Apple Silicon), Windows и Linux (альфа). Запись, расшифровка, резюме, поиск и диктовка работают на вашем компьютере без аккаунта, телеметрии и отправки аудио в чужое облако.

Без ботов

Яндекс Телемост, МТС Линк, Zoom и Teams

Нативное автоопределение созвонов в Яндекс Телемосте, МТС Линк, Zoom, Teams и Google Meet. Записывает микрофон и звук приложения на две отдельные дорожки локально — без бота в комнате. Записывайте только с согласия участников.

Русский ASR

Встроенные GigaAM, Qwen3-ASR и Whisper

Для русского языка доступны GigaAM (от Сбера), Qwen3-ASR 1.7B (10,0% WER на русском FLEURS через llama.cpp), Parakeet и Whisper large-v3 turbo. Интерфейс полностью переведён на русский язык.

Obsidian и Logseq

Чистый Markdown с YAML-свойствами

Автоматически сохраняет резюме, решения и задачи с таймкодами прямо в хранилище Obsidian или Logseq, не перезаписывая ваши ручные правки.

Диктовка и ввод

Локальная диктовка и автодополнение 56 мс

Удерживайте ⌥ Space (Mac) или Alt+Space (Windows/Linux) для локального голосового ввода в любом приложении. Опционально Gemma 4 E2B подсказывает продолжение фраз локально с учётом контекста встреч.

Для разработчиков

Read-only MCP для Claude Code и Codex

Выключено по умолчанию: при включении Claude Code и Codex могут локально искать решения с прошедших созвонов через stdio MCP без утечки данных во внешние API.

Нативный стек

Swift на Mac и Rust + GPUI на Linux/Windows

Никакого Electron: нативный Swift для macOS и нативный Rust + GPUI для Windows и Linux (.deb, .rpm, Arch, установщик и portable .zip). Android-компаньон синхронизируется с E2E-шифрованием напрямую по LAN или Tailscale.

FAQ

Частые вопросы

Работает ли LokalBot полностью без интернета и VPN?

Да. После однократного скачивания открытых моделей запись, расшифровка, резюме, поиск и диктовка полностью работают офлайн. При необходимости модели можно скачать и через зеркало HF-Mirror / ModelScope в настройках.

Как обстоят дела с Windows и Linux?

Версии для Windows (x64) и Linux (.deb, .rpm, AUR, .tar.gz) выходят как нативная альфа на Rust + GPUI и используют ту же базу SQLite, что и macOS. Установщик Windows пока без цифровой подписи, а часть Mac-функций (например, Nemotron) ещё переносится.

Какие российские сервисы и модели поддерживаются?

LokalBot умеет автоматически определять звонки в Яндекс Телемосте и МТС Линк (помимо Zoom, Teams и Meet) и поддерживает встроенную русскую ASR-модель GigaAM наряду с Qwen3-ASR и Whisper large-v3 turbo.

Есть ли подписки, лимиты минут или регистрация?

Нет. LokalBot распространяется бесплатно под лицензией GNU GPLv3 без аккаунта, без ограничений по длительности записей и без телеметрии.
