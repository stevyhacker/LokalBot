Локальные заметки встреч без облака и без ботов.

LokalBot: бесплатная open-source альтернатива Granola, Otter и Wispr Flow для macOS (Apple Silicon), Windows и Linux (альфа). В v0.14.0 встроены четыре дообученные Apache-2.0 модели: запись, расшифровка, резюме, поиск и диктовка работают на вашем компьютере без аккаунта и облака.

Без ботов

Яндекс Телемост, МТС Линк, eXpress, Zoom и Teams

Нативное автоопределение созвонов в Яндекс Телемосте, МТС Линк, eXpress, Zoom, Teams и Google Meet. Записывает микрофон и звук приложения на две отдельные дорожки локально, без бота в комнате. Записывайте только с согласия участников.

Русский ASR

GigaAM, дообученный Qwen3-ASR v3 и Whisper

Для русского языка доступны GigaAM, Qwen3-ASR 1.7B (LokalBot v3: 10,0% RU FLEURS WER, 0 галлюцинаций в тишине), Parakeet и Whisper large-v3 turbo. Интерфейс полностью переведён на русский язык.

Obsidian и Logseq

Чистый Markdown с YAML-свойствами

Автоматически сохраняет резюме, решения и задачи с таймкодами прямо в хранилище Obsidian или Logseq, не перезаписывая ваши ручные правки.

Диктовка и ввод

Локальная диктовка и Gemma 4 E2B v4

Удерживайте ⌥ Space (Mac) или Alt+Space (Windows/Linux) для локального голосового ввода в любом приложении. Опционально Gemma 4 E2B (LokalBot v4, 56/56 контекстных тестов, 20,2 мс) подсказывает продолжение фраз локально.

Для разработчиков

Read-only MCP для Claude Code, Codex и Cursor

Выключено по умолчанию: при включении Claude Code, Codex, Cursor, Windsurf, Gemini CLI и Antigravity ищут решения по вашим созвонам через локальный stdio MCP без отправки архива в облако.

Нативный стек

Swift на Mac и Rust + GPUI на Linux/Windows

Никакого Electron: нативный Swift для macOS и нативный Rust + GPUI для Windows и Linux (.deb, .rpm, Arch, установщик и portable .zip). Компаньоны для iOS и Android синхронизируются с E2E-шифрованием по LAN или Tailscale.

FAQ

Частые вопросы

Работает ли LokalBot полностью без интернета и VPN?

Да. После однократного скачивания открытых моделей запись, расшифровка, резюме, поиск и диктовка полностью работают офлайн. При необходимости модели можно скачать через зеркало HF-Mirror или ModelScope в настройках.

Как обстоят дела с Windows и Linux?

Версии для Windows (x64) и Linux (.deb, .rpm, AUR, .tar.gz) выходят как нативная альфа на Rust + GPUI и используют ту же базу SQLite, что и macOS. Установщик Windows пока без цифровой подписи, а часть Mac-функций (например, Nemotron) ещё переносится.

Какие российские сервисы и модели поддерживаются?

LokalBot умеет автоматически определять звонки в Яндекс Телемосте, МТС Линк и eXpress (помимо Zoom, Teams и Meet) и поддерживает встроенную русскую ASR-модель GigaAM наряду с Qwen3-ASR и Whisper large-v3 turbo.

Есть ли подписки, лимиты минут или регистрация?

Нет. LokalBot распространяется бесплатно под лицензией GNU GPLv3 без аккаунта, без ограничений по длительности записей и без телеметрии.
