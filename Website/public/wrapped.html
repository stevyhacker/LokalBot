Frequently asked questions

Which coding agents does Agent Wrapped read?

Agent Wrapped automatically reads local session logs from Claude Code, Codex, Cursor, Pi, OMP (Oh My Pi), OpenCode, Antigravity, and Gemini CLI. You can also pass individual --*-dir flags to point at custom log directories.

Does Agent Wrapped upload my logs or prompts?

No. The npm package has zero dependencies and makes zero network requests. It reads your local session logs, counts timestamps, tool calls, models, tokens, and git actions, and renders the card locally in your terminal and browser. Prompt text is never stored or printed.

Why does my Claude Code heatmap start 30 days ago?

Claude Code deletes detailed session logs after 30 days by default unless you add "cleanupPeriodDays": 3650 to ~/.claude/settings.json. Agent Wrapped automatically zooms to your active logged window and reads Claude Code's stats-cache.json to include earlier days counted this year.

How is Agent Wrapped connected to LokalBot?

Agent Wrapped uses the same local session-log reader as LokalBot's desktop Timeline.
