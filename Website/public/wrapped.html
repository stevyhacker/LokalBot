Frequently asked questions

      

        Which coding agents does Agent Wrapped read?
        
The CLI (npx lokalbot) reads local session logs from Claude Code, Codex, Cursor, Pi, OMP (Oh My Pi), OpenCode, Antigravity, and Gemini CLI. You can also drop Claude Code stats-cache.json, Claude/Codex/Pi/OMP .jsonl logs, or Gemini CLI session JSON files directly on this page to render offline in your browser.

      

      

        Does Agent Wrapped upload my logs or prompts?
        
No. Both the npm package and the browser file drop make zero network requests and upload zero bytes. Files dropped on this page are parsed strictly inside browser memory and never leave your tab. Prompt text is never stored or printed.

      

      

        Why does my Claude Code heatmap start 30 days ago?
        
Claude Code deletes detailed session logs after 30 days by default unless you add "cleanupPeriodDays": 3650 to ~/.claude/settings.json. Agent Wrapped automatically zooms to your active logged window and reads Claude Code's stats-cache.json to include earlier days counted this year.

      

      

        How is Agent Wrapped connected to LokalBot?
        
Agent Wrapped uses the same local session-log reader as LokalBot's desktop Timeline. LokalBot is a free, open-source (GPLv3) app for macOS, Windows, and Linux that records meetings without a bot, runs transcription and summaries locally, and exposes your meeting notes to Claude Code and Codex over read-only MCP.
