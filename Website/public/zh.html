100% 本地 · GPLv3 · v0.14.0 微调模型

完全本地运行的开源会议纪要与工作记忆。

LokalBot 是一款免费、开源（GPLv3）、无需账号的本地桌面应用（macOS 原生 Swift，Windows 与 Linux 原生 Rust + GPUI Alpha）。无需拉入会议机器人即可双轨录会，v0.14.0 默认搭载四款 Apache-2.0 微调模型，并原生支持腾讯会议、飞书、钉钉与 ModelScope 下载源。

免 Bot 录会

原生支持腾讯会议、飞书、钉钉与企业微信

直接录制麦克风与会议软件双轨音频，不向会议室拉入任何 Bot，也支持 VooV Meeting、Lark、Zoom、Teams 与 Google Meet。提示：录制前请告知并征得参会者同意。

开箱即用

内置 ModelScope 国内源与 v3 语音微调

在「设置 > 模型」中可直接切换魔搭（ModelScope）或 HF-Mirror 下载模型。默认 Qwen3-ASR 1.7B (LokalBot v3) 将静默幻觉降至 0，混读 WER 降至 12.81%，也可选 0.6B v1、SenseVoice 或 Whisper turbo。

中文全文检索

CJK 分词 + 39 ms 本地混合搜索

底层采用 SQLite FTS5 + EmbeddingGemma 2 混合检索，支持中文、日文、韩文短语任意位置匹配；在 232 场 QMSum 会议实测中，中位查询仅 39 ms、常驻内存仅 50 MB。

Obsidian 集成

自动写入 Markdown 与 YAML 属性

会议结束后自动生成带 YAML frontmatter、行动项与决策引用的 .md 笔记直写 Obsidian / Logseq 目录，并保留你手动编辑过的内容不被覆盖。

AI 编程协作

只读本地 MCP（Claude Code / Codex / Cursor）

默认关闭，按需开启后可让 Claude Code、Codex、Cursor、Windsurf、Gemini CLI 与 Antigravity 在本地检索会议决策；另支持零依赖本地年度总结 CLI（npx lokalbot）。

跨平台原生

非 Electron · 局域网端到端同步

macOS 使用原生 Swift，Windows / Linux（Alpha）采用原生 Rust + GPUI（支持 Vulkan / CUDA / CPU）。iOS 与 Android 伴侣端支持通过局域网或 Tailscale 直接端到端加密同步，不经过云端中转。

常见问题

常见问题

不挂代理能正常下载本地模型吗？

可以。在应用内「设置 > 模型」中将下载源切换为 ModelScope（魔搭）或 HF-Mirror 即可直接高速下载，下载完成后全程断网也能离线录会、转写与总结。

为什么不会向会议里拉入机器人？

LokalBot 直接在你的电脑本地采集麦克风与会议软件音频流，不调用会议平台账号，也不会作为参会者加入房间。因此你仍需自行告知参会方正在录制。

Windows 和 Linux 版本目前可用程度如何？

Windows（x64）与 Linux（.deb / .rpm / AUR / .tar.gz）目前为原生 Rust + GPUI Alpha 版，与 Mac 版共享完全一致的本地 SQLite 数据库格式；Windows 安装包尚未完成代码签名，部分 Mac 专属能力仍在移植中。

支持把外部模型或已有订阅接进来吗？

支持。除内置本地模型外，你可以按需启用 Ollama、任意 OpenAI 兼容接口或你自己的 Claude / ChatGPT / Gemini / Antigravity 订阅；任何远端服务必须经你明确授权后才会发送上下文。
