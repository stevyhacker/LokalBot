## What’s new

- **Import meetings from Wispr Flow (Mac).** **Recording → Import Meetings From → Wispr Flow…** and `lokalbot-cli import wispr-flow` read meeting titles, times, participants, summaries and speaker-attributed transcripts from Wispr Flow's folder or `flow.sqlite` (read-only, skipping deleted meetings, tours and in-call drafts). Onboarding and the empty meeting list also offer **Import from Wispr Flow…** when Wispr Flow is on the Mac, and unreadable transcript files are skipped so a later import picks them up. Thanks to bkcraft-1.
- **Faster first-run setup and desktop recap sharing (Mac, Windows and Linux).** On the Mac, setup loads the bundled sample meeting right away with precomputed notes and transcript while models download, defaults Macs under 16 GB of memory to **Lightweight local** (`1.55 GB`), and adds **Apple on-device (0 GB)** on macOS 26+. Windows and Linux add **Copy recap for Slack / Email**, **Export as HTML…** and a model preset picker during setup. All desktop apps add an off-by-default attribution toggle for copied recaps and follow-ups, and Mac Autocomplete statistics adds an aggregate-only **Save Stats Card (PNG)** export.
- **Next meeting card always visible on Today (Mac, Windows and Linux).** Today now shows your next unrecorded meeting card and pre-meeting prep however far ahead it is, including a meeting already under way.
- **Record meetings before pairing (iPhone, iPad and Android).** Tap **Record a meeting** on the welcome screen to record on your device before connecting a computer. Recordings stay in backup-excluded local storage with no network traffic and transfer over the encrypted link once you pair. Shared Ask answers also list cited meetings under `Sources:`.
- **Download status in model pickers (Mac, Windows and Linux).** On Windows and Linux, **Change…** puts a download icon on local models that are not on disk yet. On the Mac, undownloaded rows say **Not downloaded**, including under **In use** when selected. Thanks to SamLeatherdale.

## Improvements

- **Faster Qwen3-ASR dictation on Automatic (Mac).** When the first language-free decode already matches the voted language (up to 24 speech spans, outside Serbian, Croatian, Bosnian, Japanese and Chinese), LokalBot keeps that decode and skips the second pass. On the default LokalBot v3 weights, Automatic dictation takes about 0.58× as long, close to a pinned language. Thanks to bkcraft-1.
- **llama.cpp v1.1.0 (`b12774`) and updated autocomplete decoding (Mac, Windows and Linux).** Updates `llama.cpp` from `b12613` to the tagged `v1.1.0` release across every platform, picking up upstream Inkling 2 tokenizer, chat-parser and graph fixes (about 21% faster Inkling 2 Mini generation on a Radeon RX 6600 XT). On the Mac, in-process autocomplete now decodes with `llama.cpp`'s extended batch API (`llama_batch_ext`).
- **Bounded quit shutdown (Mac).** Quitting settles any active recording save first and blocks new recordings once saved, then caps remaining engine shutdown at 10 seconds so a stuck worker no longer requires Force Quit. Thanks to bkcraft-1.
- **Calendar-linked desktop Telemost audio (Mac).** Desktop Telemost calls matched to a calendar room link now bind system audio to the native desktop app so capture attaches reliably. Thanks to region23.
- **Timeline date pill alignment (Mac).** The `Today` and `Yesterday` label now sits inside the toolbar button with matching padding on both sides and one full-pill hit target.

## When you update

- **llama.cpp updates to v1.1.0 (`b12774`) on Windows and Linux.** The bundled `llama-server` runtime downloads once in the background (about 23–39 MB for CPU or Vulkan). With an NVIDIA GPU, set CUDA up again when asked.

New strings in non-English languages are machine translations. The CUDA builds of llama.cpp b12774 weren't run on an NVIDIA GPU. Windows and Linux remain in alpha, and the Windows app isn't code-signed. The iPhone and iPad app is on the [App Store](https://apps.apple.com/app/id6836773709). The Android app is on [Google Play](https://play.google.com/store/apps/details?id=me.dotenv.lokalbot.companion) and here for Android 10 or later, signed with different keys, so one can't update the other.
