## Improvements

- **Faster local meeting notes, transcription and Vulkan autocomplete (Mac, Windows and Linux).** Multi-part local meeting summaries now run two extraction slots in parallel with a unified KV cache, shared prompt caching and larger micro-batches, speeding up 4-part notes by about 1.2× (`47.97 s` to `38.81 s` on M4 Max; `103.94 s` to `86.08 s` on Radeon RX 6600 XT Vulkan) while stepping back to single-slot execution on high-reasoning Think models. On the Mac, batch Qwen3-ASR transcription now decodes three speech spans in parallel with bounded context, running about 1.7× faster (`20.86 s` to `12.12 s`, `55.4×` real-time on M4 Max) with unchanged WER on the sample tracks. On Windows and Linux, Gemma 4 E2B autocomplete turns off Flash Attention on Vulkan, cutting warm completion latency by about 16.5% (`200.1 ms` to `167.0 ms` on RX 6600 XT).
- **Smaller default Gemma 4 E2B autocomplete download (Mac, Windows and Linux).** Fresh installs and upgrades from stock Gemma 4 E2B now use the `i1-Q5_K_M` + `Q4_K` Per-Layer Embedding quant (`Gemma-4-E2B-LokalBot-v4-i1-Q5_K_M-pleQ4K.gguf`, `3.02 GB`) instead of `i1-Q6_K` (`3.85 GB`), cutting `785 MiB` (`-21.4%`) off download size and combined RAM+VRAM (`-578 MiB` host RAM, `-208 MiB` VRAM) and reducing RX 6600 XT Vulkan latency by ~7–10% with matching accuracy (`57.3%` / `94.0%` precision on blind holdout, `26/26` saved-memory recall, `0` unsafe checks).
- **Dictation word lock for digits, names and negation (Mac).** Cleaned direct dictation now checks output against the raw transcript so spelled-out numbers that replaced spoken digits are restored as digits, and falls back to the raw transcript if cleanup drops a negation, proper name or time/decimal, while still letting self-corrections and repeated false starts be cleaned up. Thanks to bkcraft-1.

## When you update

- **Existing `0.14.0` and `0.14.1` LokalBot v4 autocomplete models stay put (Mac, Windows and Linux).** The previous `i1-Q6_K` build stays in the catalog as **Gemma 4 E2B (LokalBot v4, Q6)**, so updating from the `0.14.0`/`0.14.1` default keeps your downloaded model working with no forced 3 GB re-download, and you can switch to the smaller `3.02 GB` default anytime in **Settings > Models**. If you are still on the older stock **Gemma 4 E2B Base** Q6 build, LokalBot offers a one-click switch to the `3.02 GB` Q5 default (which downloads the new file if you accept).

Windows and Linux remain in alpha, and the Windows app isn't code-signed. The iPhone and iPad app is on the [App Store](https://apps.apple.com/app/id6836773709). The Android app is on [Google Play](https://play.google.com/store/apps/details?id=me.dotenv.lokalbot.companion) and here for Android 10 or later, signed with different keys, so one can't update the other.
