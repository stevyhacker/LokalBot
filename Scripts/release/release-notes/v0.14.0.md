## What’s new

- **Fine-tuned LokalBot models are the new defaults (Mac, Windows and Linux).** Fresh installs now default to Apache-2.0 fine-tuned models trained on open-license datasets: `Qwen3.5 4B (LokalBot v4)` for Think, `Gemma 4 E2B (LokalBot v4)` for Autocomplete, and `Qwen3-ASR 1.7B (LokalBot v3)` and `0.6B (LokalBot v1)` for transcription on the Mac. Existing installs keep their current models until you choose **Upgrade** from the dismissible card on **Today** or in **Settings → Models**.
- **Meeting waveform zoom, trim and split (Mac).** The meeting player waveform is 1.5× taller with cursor-anchored zoom (up to 30×) and horizontal panning. Click twice to mark a range, then **Trim to Selection** or **New Meeting from Selection** to clean up long recordings or split back-to-back calls. Clicking the player caption jumps to that line in the transcript from any tab.
- **Antigravity, Gemini and T3 Code support (Mac, Windows and Linux).** **Settings → Models** adds **Antigravity plan** (`agy` CLI) and **Gemini plan** (`gemini` CLI) as Think backends, running your signed-in CLI in a temporary folder with tools and extensions turned off and separate approval per origin. **Settings → Screen & activity** (Mac) and **Settings → Day Memory** (Windows and Linux) add toggles to read local **Antigravity** and **T3 Code** coding-agent sessions alongside Claude Code and Codex.
- **Custom call apps, eXpress and optional browser call detection (Mac and Windows).** LokalBot now detects **eXpress** calls, lets you pick additional native call apps with a file picker in **Settings → Meetings**, and adds an opt-in switch to detect calls in other browser sites while blocking private windows. Thanks to region23.
- **Reprocess meetings from the terminal (Mac, Windows and Linux).** `lokalbot-cli reprocess <id>` runs the same Reprocess flow as the meeting menu (`--transcribe`, `--no-summary`, `--wait`) and keeps previous notes in `summary.previous.md`. Requires **Allow external agents to change LokalBot settings**; Agent Mode still asks before running it.
- **Wispr Flow dictionary import and smarter dictation spacing (Mac).** **Settings → Models → Transcribe → Advanced** adds **Import from Wispr Flow…** to bring dictionary words from `flow.sqlite` into Names and vocabulary (read-only, skipping snippets and deleted entries). Dictation also checks the text before the caret right before pasting to add a leading space after a word and lowercase everyday English words mid-sentence. Thanks to bkcraft-1.

## Improvements

- **Model-default reasoning, Inkling 2 Mini and llama.cpp b12613 (Mac, Windows and Linux).** Think tasks now use each model's own default reasoning instead of per-task budgets (LokalBot Qwen3.5 4B fine-tunes stay Off under Automatic, and instant tasks like Compose, selection actions, window handoff and short CLI/MCP answers keep reasoning off). Adds **Inkling 2 Mini** as an opt-in Think model and updates `llama.cpp` to `b12613`.
- **Wayland autocomplete stops committing on focus loss (Linux).** KDE Plasma draws suggestions in a click-through overlay pill (`zwp_input_panel_v1`), and Sway and Hyprland use an input-method popup (`zwp_input_popup_surface_v2`), so unaccepted suggestions no longer commit into Chromium, Electron, Firefox or Thunderbird when you click away.
- **More reliable Windows autocomplete (Windows).** Overhauls UIA focus and range reading (including detached WebView2, CEF and Tauri windows), per-monitor DPI overlay placement, atomic keyboard-hook ordering and session reconciliation.
- **Autocomplete privacy, KV reuse and accept UX (Mac, Windows and Linux).** Adds double-tap acceptance, an optional setting to let Tab move to the next field in single-line inputs, and an option to pause autocomplete in Low Power Mode. Tightens filtering for password, credential and search fields, sensitive clipboard lines, invisible or bidi control characters and composer UI chrome, and turns on `--swa-full` for Gemma 4 KV reuse.
- **Cleaner Today layout and preserved digests (Mac, Windows and Linux).** Yesterday's brief now spans full width below Today's top columns, long action due phrases wrap cleanly, and checking off an action item or running an unchanged meeting rewrite no longer clears Dream reports or past day digests.
- **Better language handling and fixes (all computers).** Meeting notes keep the detected transcript language instead of falling back to a weak runner-up, the notes language menu adds Bosnian, Croatian, Montenegrin, Serbian and Ukrainian, daily reports use your note and interface language for durations and labels, and Russian plural counts read cleanly on Windows and Linux. Also keeps New Teams capture on `modulehost` while a helper plays chimes (Mac), fixes two-line menu bar row height (Mac), and fixes a Windows per-app audio loopback memory bug.

## When you update

- **Existing models stay put (Mac, Windows and Linux).** Updating never forces a download of the new fine-tuned defaults; use the upgrade card on **Today** or in **Settings → Models** whenever you want to switch.
- **llama.cpp updates to b12613 (Windows and Linux).** The bundled `llama-server` runtime re-downloads once and re-probes `--swa-full` support.

New strings in non-English languages are machine translations. Windows and Linux remain in alpha, and the Windows app isn't code-signed. The iPhone and iPad app is on the [App Store](https://apps.apple.com/app/id6836773709), with export compliance declared in the app for automated release submissions. The Android app is on [Google Play](https://play.google.com/store/apps/details?id=me.dotenv.lokalbot.companion) and here for Android 10 or later, signed with different keys, so one can't update the other.
