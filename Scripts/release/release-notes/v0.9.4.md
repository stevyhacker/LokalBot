## What’s new

- **Meeting notes get through provider rate limits.** When your Think model runs on OpenRouter or another server, LokalBot now sends it fewer requests at once and pauses all of them when the server says it’s busy. Meeting notes go ahead of scheduled work and get up to five attempts, so a busy provider no longer leaves a meeting with failed notes. Ask is never queued behind background work.
- **Overnight review no longer gets stuck.** Changes to screen memory, activity, or today’s digest used to discard past reviews, so the same week was reviewed again and again. They now affect only the days they touch. Each review now caps how long the model reasons, and a rate-limited review tries again later instead of right away saving a shorter fallback.
- **Fewer repeat digest runs.** When the day digest is refreshed, parts of the day that haven’t changed reuse their earlier answers. Long work sessions are now summarized in proportion to their length, so a six-hour block is no longer squeezed into a single summary.
- **Quieter meetings.** Brief audio hiccups no longer trigger “Recording needs attention” notifications mid-call, and a handful of dropped audio buffers no longer marks a recording as interrupted. Real problems, such as a full disk or missing audio, still notify you.
- **Smoother while idle.** LokalBot does much less work on the main thread between meetings and returns more memory when speech models unload.
- **Silent recordings finish.** A recording with no speech now ends as “No speech detected” instead of failing and retrying on every launch.
- **Cleaner transcripts and notes.** Only projects you pinned are used as transcription vocabulary, so unconfirmed project names no longer steer what the speech model hears. Smaller local models no longer show internal source IDs as an action’s due date.
- **Quick Recall puts exact matches first.** A screen that contains the words you searched for now ranks above screens that are only loosely related.
- **Timeline shows the day’s totals next to your sessions.** Day Overview now sits directly above Work Sessions.
- **Smoother transitions.** Completing an action, the Undo bar, the Copy button in Ask, setup checkmarks, and onboarding pages now animate instead of jumping. Reduce Motion turns this off.
