## What’s new

- **More reliable dictation with Bluetooth headsets.** Dictation handles microphone format changes and reconnects, shows when audio stops arriving, and keeps speech captured before an input failure.
- **Dictation reaches the intended field more reliably.** Replacing selected text, slower apps, cancellation, and consecutive dictations have improved delivery handling, with clearer clipboard fallback messages.
- **Clearer recording and delivery feedback.** The recording indicator waits for microphone audio, the level bars follow your voice, and an optional sound tells you when the microphone is ready. When a readable field does not show the pasted text, the overlay offers Copy.
- **Choose how you dictate.** Record a key combination or a modifier-only chord such as Control–Option, choose your microphone, or try Tap or hold in Settings → Dictation. Esc cancels a starting or active recording, and a warning explains when macOS Secure Input blocks the shortcut.
- **Compose better preserves direct dictation.** Ordinary questions and relayed sentences use a cleanup prompt that treats them as text to insert. Writing requests can use the newest focused-window text, and Last result shows which context contributed.
- **Less repeated work for short Qwen dictations.** Short recordings avoid an unnecessary second decode; recognition can retry without vocabulary hints when those hints overwhelm the result.
- **Menu bar text follows macOS sizing at the default setting.** Larger text choices remain available.

### After updating

The microphone-ready sound is enabled by default and can be disabled in Settings → Dictation. Existing installs keep Option–Space as the default shortcut, and the microphone continues to follow the system input unless you choose another one. Optional Compose context grants remain unchanged.

Paste confirmation briefly checks only the original non-secure field and discards the text it reads. Unreadable fields and excluded apps are left unchecked.
