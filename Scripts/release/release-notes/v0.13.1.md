## What’s new

- **A calmer Windows and Linux app.** The Mac's redesign from 0.13.0 comes to Windows and Linux: Actions has its own page, Today and meetings are laid out in panels, you name voices with **Name speakers…**, Settings opens in its own window, setup downloads nothing until you ask, and Ctrl+K opens Quick Recall in place of the command palette. [How it works](https://www.lokalbot.com/explainers/windows-linux-app-tour.pdf)

## Improvements

- **llama.cpp 1.0 (all computers).** On a Radeon RX 6600 XT with Vulkan, Qwen3.5 0.8B writes about 1.8× faster. Answers and speed on the Mac are unchanged.
- **Leaner Qwen transcription (Mac).** It keeps 4 MB of spare memory after each window instead of 2.9 GB, and runs about 13% faster.
- **Parakeet keeps the start of long recordings (Mac),** and an interrupted model download resumes.
- **Agent Mode on pi 1.5.2,** with less CPU and memory for large tool calls.
- **Fixed on Windows and Linux:** in-app Pause and Resume, numbers in right-to-left languages, and Back in narrow windows.

## When you update

- **Windows and Linux.** A meeting has no Review tab. In Ask, Enter always asks (↓ then Enter opens a match), and a full question across all sources also reads work memory and About you. Agent Mode's read-only lookups of your library run without asking when its model is on this computer. People keeps the next seven days of calendar events in memory, and the tray menu leaves out attendee names.
- **Runtimes download again once:** Agent Mode's (65–80 MB) everywhere, and llama.cpp's on Windows and Linux. With an NVIDIA GPU, set CUDA up again when asked.

The redesigned screens were checked on Linux and on one Windows PC, but not on real Wayland, KDE or GNOME desktops or the Windows tray, and their new strings are machine translations. The CUDA builds weren't run on an NVIDIA GPU. Windows and Linux remain in alpha, and the Windows app isn't code-signed. The Android app is on [Google Play](https://play.google.com/store/apps/details?id=me.dotenv.lokalbot.companion) and here for Android 10 or later, signed with different keys, so one can't update the other. The iPhone and iPad app isn't in the App Store yet.
