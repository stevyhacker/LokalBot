## What’s new

- **Redesigned Models settings.** Separate Active models, Downloaded, and Connections pages make it easier to choose models, manage downloads, and configure providers. Focused pickers, preset previews, and setup checks guide changes; current models stay active while replacements prepare, and completed switches can be undone. Settings now open in the main window, and model pickers adapt to smaller displays.
- **Qwen3-ASR is now recommended.** New installations and the Recommended model stack use Qwen3-ASR 1.7B for local transcription. Existing saved model selections are preserved, and Granite remains available.
- **More reliable transcription.** Fixed a Qwen crash on very short audio spans, avoided unnecessary decoding of confirmed silence, and improved cleanup of repetitive transcription loops. Granite now reuses its loaded speech runtime across audio regions instead of repeatedly restarting it.
- **Clearer speaker identity.** Personal microphone speech defaults to “Me,” while explicit corrections survive reprocessing. Optional visual speaker identification for Google Meet and local voice profiles help name participants, with uncertain matches kept reviewable and controls to manage remembered speakers.
- **Better action ownership and evidence.** Summaries and action items retain validated source citations. Ownership handling better recognizes explicit commitments and conversational acceptance while leaving ambiguous requests, reported speech, and unsupported assignments unresolved.
- **Meeting notes that can recover.** Long or interrupted generation saves validated progress and can resume unfinished extraction or repairs. The meeting view shows clearly labeled partial recaps and actions instead of an empty result; partial actions remain read-only until completion. Cloud request planning and output budgets have also been improved.
- **Updated local model options.** Semantic search now uses Harrier 0.6B and rebuilds incompatible older indexes. Granite Speech 5 is available as an optional fast English transcription mode. Local text requests with no thinking budget now explicitly disable thinking.
- **Faster release validation.** Builds and hosted UI checks reuse verified test products, run independent checks in parallel, and can prepare signed release archives while validation finishes.
