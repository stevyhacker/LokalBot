## What’s new

- **Use a transcription server of your choice.** Settings → Models → Transcribe now supports speech-to-text servers for meetings and dictation, including OpenAI, Groq, OpenRouter, and whisper.cpp on another computer. Speaker separation and word timing still run on your Mac.
- **Run autocomplete on a server.** Choose Think’s server or a separate OpenAI-compatible server under Settings → Models → Autocomplete. Writing settings now explain server problems and missing suggestions, and chat-model suggestions preserve the space before a new word.
- **Download models with less disk work.** Model downloads write each chunk directly to its destination, avoiding a second copy and leftover temporary parts after an interrupted download.
- **Give Ask more complete evidence.** Search results now include whole matching lines, preserving nearby context such as “not.” Attached screen sources can be cited, with tighter handling of dates and deleted sources.

On-device processing remains the default. Sending audio or autocomplete context to another computer requires a separate approval for each feature’s server; approving Think alone does not enable either.
