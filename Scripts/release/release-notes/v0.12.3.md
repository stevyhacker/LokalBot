## What’s new

- **Hand off work to an agent (Mac).** After a meeting's summary, each open action that is yours can become an Agent Mode task with a prompt and the meeting attached. A shortcut (⌃⇧H) does the same for the window in front of you: LokalBot reads it once, your Think model writes a brief, and you send it to Agent Mode, Claude Code or Codex. Both are off by default, in Settings → Meetings → Processing and Settings → Ask. [How it works](https://www.lokalbot.com/explainers/agent-handoff.pdf)
- **Live Radar and Follow-through (Mac).** Live Radar catches commitments, decisions, open questions and conflicts with earlier meetings while you record, and can answer a question from your screen memory or your work. Follow-through plans the work for one action and drafts each step (an email, an invitation, a task for a coding agent) for your approval. Both read with your Think model, so with a model on this Mac nothing leaves it. Turn Live Radar on in Settings → Meetings → Live Radar, then press Start Radar during a recording. [How it works](https://www.lokalbot.com/explainers/live-radar.pdf)
- **Turn-by-turn live text (Mac).** The live transcript preview can transcribe one turn at a time, so a turn's text follows its speaker by about half a second to a second, where it otherwise takes about two and up to five. Off by default, in Settings → Meetings → Processing.
- **Autocomplete on KDE Plasma (Linux).** Suggestions in other apps now work on Plasma's Wayland session. Turn autocomplete on, then choose LokalBot in System Settings → Keyboard → Virtual Keyboard. [How it works](https://www.lokalbot.com/explainers/wayland-autocomplete.pdf)

## Improvements

- **Dictation keeps working when the server fails (Mac).** If your transcription server rejects the key or can't be reached, a speech model already on this Mac transcribes the same audio. A dictation that ends without text now says why, where you are typing.
- **Text recognition can't freeze capture any more (Mac).** One macOS text-recognition request that never returned could stop screen capture, autocomplete and Files for the rest of the day. Each now waits only to its own limit, and the main window offers Relaunch if recognition stays stuck.
- **Privacy promises kept (Mac).** A paired phone's Ask reads only what you share with it. Revoking a transcription server stops the rest of that meeting's uploads, and revoking a server ends a running Agent Mode turn. On the Claude plan, nothing from a meeting is on the `claude` command line. Voice samples of merged meetings now expire, and the overnight review no longer reads the sample meeting.
- **Fewer crashes (Mac).** A model's tool call with an out-of-range value, and reprocessing a meeting whose notes repeat an action, could each stop the app.
- **Speech models download again (Windows and Linux).** Parakeet v3 and v2 failed to download after their files changed upstream. Recordings waiting for a model are now processed when it arrives.
- **Steadier Windows and Linux app.** One unreadable setting no longer resets all settings, a malformed JPEG no longer stops file indexing, and a hung audio system no longer hangs the app. A dictation doesn't wait for a meeting's transcription, dictated text stays out of clipboard history, clicking a notification on Linux opens it, and accepting a suggestion with emoji or Cyrillic inserts the right text in GTK and Qt apps.
- **Android app.** The People list no longer crashes on a date without a time zone, a queued question now shows its answer, and lists go past 1,000 meetings. App Lock now covers the recents picture and can't be skipped after the app restarts.
- **For agents (all platforms).** `lokalbot-cli` prints an error code before an access refusal, such as `[access_disabled]`, and `get_meeting` refuses an `include` value it doesn't know. `LokalBot.mcpb` is attached to each release from now on. There are also [plugins for Claude Code and Codex](https://www.lokalbot.com/claude-code-codex-plugins).

## When you update

- **Claude plan.** Structured requests now go to Claude Code on standard input. A Claude Code version that ignores the answer format gives an error where it used to return prose, so update Claude Code if notes fail.
- **Agent Mode on the built-in model (Mac).** A task holds the model only while it works, so after ten idle minutes the next prompt waits for the model to load.
- **Calendar links over `http://` (Windows and Linux)** are refused unless they are on this computer. A saved link is kept and shown as refused.
- **KDE Plasma.** Choosing LokalBot under Virtual Keyboard replaces Fcitx or IBus there. After a later LokalBot update, log out and back in once.
- **macOS 26, right-to-left languages.** The window's sidebar stays on the left, as a precaution against a crash there.

Hand off, Live Radar on a local Think model, Follow-through and turn-by-turn live text are covered by automated tests but haven't been through real meetings and daily work yet. Live Radar and Follow-through were first built on a hosted model; speed on a small local model hasn't been measured. Autocomplete on KDE was run on headless KWin 6.8 with stand-in suggestions, not on a real Plasma desktop, and not in Firefox or Chrome there. A separate fast live text option in Settings → Meetings → Meta Muse sends meeting audio to `api.meta.ai`, and only after you add a key and approve it.

Windows and Linux remain in alpha, and the Windows app is not yet code-signed. Nothing in this release was run on Windows by hand. The Android app is a direct download for Android 10 or later; the iPhone and iPad app isn't available yet.
