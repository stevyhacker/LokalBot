## What’s new

- **Accurate semantic search.** LokalBot now uses the embedding model’s correct pooling mode, safely splits unusually long transcript segments, rejects vectors made with the old contract, and rebuilds enabled semantic indexes in the background.
- **Action items that keep your work visible.** Meeting outcomes retain every action owned by you, repair inconsistent first-person ownership, and surface only the five highest-priority actions owned by other participants instead of flooding the recap.
- **Safer encrypted local data.** Temporary Keychain read failures can no longer look like first use and replace the keys protecting screenshots or chat history. New encryption keys are created atomically, verified before use, and never overwrite an existing item.
- **Cleaner Day Digest instructions.** The custom-instructions field is now a stable multiline editor with consistent alignment and a clearer example.

**Full changelog:** https://github.com/stevyhacker/lokalbot/compare/v0.7.1...v0.7.2
