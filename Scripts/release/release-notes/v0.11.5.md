## What’s new

- **Connect Gmail read-only (Mac).** In Settings → Personal Context → Email, connect one or more accounts to keep selected conversations encrypted on your Mac. This release adds the connection and local sync; meeting briefs and other features do not use the downloaded mail yet. Google has not verified LokalBot’s Gmail access, so its sign-in shows an unverified-app warning and is limited to the first 100 users.
- **See work by project in Timeline (Mac).** Saved Claude Code and Codex activity can name work sessions by project and task, show related pull requests and commits, and split the day by project. Sessions without matching agent activity continue to use app-based names.
- **Try Granite Speech 5.0 2B (Mac).** Choose the optional transcription model for meetings and dictation. Its download is about 3.12 GB; the default transcription model is unchanged.

Windows and Linux remain in alpha. The Windows app is not yet code-signed.
