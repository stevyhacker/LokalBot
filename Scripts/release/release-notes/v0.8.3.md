## What’s new

- **More dependable meeting capture.** Browser lifecycle checks now distinguish temporary Accessibility and Chromium host interruptions from an ended call, keep a bounded reconnect window, prefer a verified in-call browser target, and can attach meeting audio late without capturing unrelated browser media.
- **Safer speaker attribution.** Microphone and system tracks remain separate, unverified speech stays unresolved, and derived transcript and summary evidence is bounded to the verified meeting content range.
- **Summary recovery that finishes.** Truncated structured output gets one bounded expanded retry; malformed source-less records receive focused recovery; legacy failed checkpoints can restart cleanly; and an unavailable speaker-identity sidecar no longer blocks an otherwise usable summary.
- **Configurable notes-generation budgets.** Conservative, Default, Generous, and Unlimited presets let custom Think backends trade runtime and output headroom explicitly.
- **Updated product documentation.** README screenshots, demo media, and capture notes now reflect the current app experience.
