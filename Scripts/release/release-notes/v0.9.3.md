## What’s new

- **Your day digest now includes coding agent work.** The digest picks up what Claude Code and Codex did in the background: what you asked for, commits, pull requests, and changed files. Session files are read on your Mac only and follow your screen-text retention. To turn it off, exclude folders, or delete what was saved, go to Settings → Day Memory → Coding agent sessions.
- **Meeting notes finish more often.** Long meetings no longer end as “Partial notes” just because one task’s owner couldn’t be confirmed. That task now shows an unclear owner instead. Longer meetings also get a larger processing budget, and notes no longer get stuck with “cannot fit the model’s input allowance.”
- **Faster notes with OpenRouter models.** LokalBot now uses the context window OpenRouter publishes for your chosen model, so long meetings are split into fewer, larger parts.
- **More accurate Qwen3-ASR transcripts.** With speaker detection on, LokalBot transcribes the whole recording first and then assigns each word to its speaker. On our meeting benchmark this nearly halved transcription errors. With the language set to Auto, each speaker’s track also settles on one language, so a laugh no longer turns into Chinese. A small word-alignment model downloads automatically when first needed.
- **See what each preset installs.** The Models page lists the transcription, thinking, and autocomplete models each preset sets up.
- **Panes keep their width.** Selecting a Timeline work session no longer widens the sessions rail, and the same fix applies to every split view.
- **Quicker startup on large libraries.** The launch-time cleanup of old screen memory takes about a third of the time it used to.
- **Easier troubleshooting.** Settings has a new Export Diagnostics… button that gathers logs, health reports, and settings without passwords or keys. It never includes meeting audio, transcripts, notes, or screenshots. A Run Health Check Now button checks your library on demand.
