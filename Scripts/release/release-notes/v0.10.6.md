## What’s new

- **Use your ChatGPT or Claude plan.** Choose either plan in Settings → Models → Think for Ask, meeting notes, and daily summaries, without an API key. ChatGPT uses browser sign-in; Claude uses your installed, signed-in Claude Code. Each plan asks for its own approval before receiving context, and usage-limit errors stop the request. These plans do not support Agent Mode.
- **More responsive search while indexing.** Ask and Quick Recall reuse the same query embedding across meeting and screen search. Background indexing works in smaller batches and gives typed queries priority.
- **Keep screen search up to date.** When semantic screen search is enabled, new screen text is indexed automatically in batches. Interrupted indexing resumes on launch, and failed passes retry.
- **More reliable local models.** Development and test copies use separate model-server ports and runtime files, preventing them from blocking the installed app. LokalBot also recovers model servers left behind by a terminated app.
