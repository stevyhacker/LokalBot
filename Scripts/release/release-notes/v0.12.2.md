## What’s new

- **The Android app, as a download.** `LokalBot-0.12.2-android.apk` is attached to this release, for Android 10 or later. Install it, then pair it from Settings → Phones & tablets on your computer. It isn't on Google Play yet and doesn't check for updates, so install each new APK over the old one. The iPhone and iPad app isn't available yet, because those can't install from a download.
- **Record a meeting on your phone.** The phone records and sends the audio to your paired computer, which makes a meeting from it. The phone deletes its copy once the computer confirms it has stored the meeting. To stop accepting recordings, turn off **Accept recordings from my devices** in Settings → Phones & tablets. This has only run on an emulator so far, with no real phone or real microphone, so don't rely on it yet for a meeting you can't afford to lose.

## Improvements

- **Faster on-device models (all platforms).** llama.cpp moves to v0.9.0. Gemma 4 E2B, the default autocomplete model, reads prompts about 3 times faster on an M4 Max and about 10% faster with CUDA on an RTX 3060.
- **Ask says when a question is limited (all platforms).** With a date filter, chosen meetings or a device's shared history window, Ask tells the model the limit, so it no longer calls those results your whole library. Questions from a phone or tablet read everything shared with it. Starting from a day or a meeting only sets where the answer starts.
- **Better meeting notes and answers (Mac).** A decision stated outright reaches Decisions even when the model filed it elsewhere, for English meetings with the Meeting template. Transcript lines no longer start with a stray period, answers show formatted text while they stream instead of raw `**`, and Compose no longer writes the window title or markdown into plain text.
- **Fewer failed answers on a slow Mac (Mac).** Answers wait up to 5 minutes for the model server instead of 2, which a just-booted Mac could run past.
- **Steadier Projects and panes (Mac).** Split panes keep their width on the first selection. The open project is highlighted, hardware names such as "SSD" are no longer suggested as projects, and a new project note shows when it finished, not when it started. The toolbar title now follows a live meeting.

## When you update on Windows or Linux

- The app fetches the new on-device runtime in the background when it starts and removes the old one, so you don't need to download it again in Settings. If you use CUDA, a message asks you to set it up again, because that download is larger.

Windows and Linux remain in alpha, and the Windows app is not yet code-signed. This llama.cpp build hasn't been run with CUDA on Windows.

Release downloads no longer include `.sha256` files. The release page shows each file's SHA-256, and GitHub's API returns it as `digest`.
