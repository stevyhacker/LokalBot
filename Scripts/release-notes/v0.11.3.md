## What’s new

- **NVIDIA CUDA acceleration (Windows and Linux, experimental).** Choose **CUDA (experimental)** in **Settings → Models → llama.cpp** to accelerate the built-in Think, search and autocomplete models on a supported NVIDIA GPU. Setup selects a compatible CUDA runtime and downloads the libraries it needs; the full CUDA toolkit is not required. **Automatic** still selects Vulkan or CPU. Transcription and speaker separation keep their existing CPU engines.
- **Easier Personal Context review (Mac).** Settings → Personal Context now separates **To review**, **Kept**, **Learning**, and **Agents**. Keep or dismiss suggestions together, see the words they came from, and browse kept items grouped into facts, preferences, goals, and principles.
- **Agent Mode knows its way around LokalBot.** Updated instructions guide the agent to your permitted meeting history, actions, people, and shared personal context. Each run includes the current date, time zone, selected model, and whether it is working in Agent Workspace or a folder you chose.
- **Read several meeting summaries at once.** `lokalbot-cli list --include summary` and MCP’s `list_meetings` with `include: "summary"` return summaries together. Long summaries are shortened and marked, and individual meetings can still be read in full.

## Fixes

- `lokalbot-cli brief` now points shell agents to CLI commands they can run.

The Mac installer is named `LokalBot-0.11.3-macos-arm64.dmg`, with a matching `.sha256` file. Update download scripts that expect the fixed name `LokalBot.dmg`.
