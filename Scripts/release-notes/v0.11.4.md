## What’s new

- **Run Agent Mode with your ChatGPT plan.** After signing in and approving plan access, use Agent Mode on Mac, Windows, and Linux with your ChatGPT subscription. Requests count toward the plan’s usage limits. Claude-plan Agent Mode remains unsupported.
- **Find speaker names as you type.** Type in the Name field to filter suggested attendees. Return or Enter selects the first match; press it again to save.
- **Open action items in Claude Code or Codex (Mac).** The action menu prepares a prompt with the task and its source meeting context for you to review and send.
- **Choose Ukrainian transcription explicitly (Mac).** Select Ukrainian in Advanced → Language & vocabulary. Whisper uses the selected language; supported Parakeet models accept a Cyrillic-script hint. Real Ukrainian audio accuracy has not been validated.

## Fixes

- **More reliable meeting recording (Mac).** Webex capture now follows its media helper, Google Meet detection recognizes room links under `/meet/`, and recordings warn when a microphone keeps producing digital silence.
- **Faster default autocomplete (Mac).** The default pause before suggesting is now 100 ms, down from 160 ms. Existing saved settings are preserved.
- **GPT-6 reasoning settings.** Notes, Ask, digests, and Agent Mode now send the selected reasoning level to GPT-6 models.
- **Built-in model startup on fresh installations (Windows and Linux).** Windows packages include the required Visual C++ runtime; Linux packages declare the OpenMP dependency. Missing-library errors give clearer recovery steps.

Windows and Linux remain in alpha.
