## What’s new

- **Windows and Linux catch up with the Mac.** Files, screens by meaning, the overnight review, selection actions, spoken summaries, People, Projects and Actions, Personal Context, coding-agent sessions, routines and exports, agent handoff, the command palette, and Settings by feature. [How it works](https://www.lokalbot.com/explainers/windows-linux-app.pdf)
- **Autocomplete on Wayland (Linux).** Suggestions in other apps on Sway, Hyprland and GNOME, as an input method. KDE isn't supported yet. [How it works](https://www.lokalbot.com/explainers/wayland-autocomplete.pdf)
- **Screen text in more scripts (Windows and Linux).** Screen search reads beyond Latin script, with Tesseract on Linux and Windows' own recognizer on Windows.

## Improvements

- **Phones and tablets, ahead of the apps (all platforms).** Settings → Phones & tablets is here, off by default. The iPhone, iPad and Android apps aren't in the App Store or Play Store yet.
- **Autocomplete in more places (Mac).** Faster in Chrome, and the suggestion shows correctly on Cyrillic in fields that report no caret, such as Viber.
- **Read aloud downloads again (Mac).** A fresh download of the voice model failed its check after upstream replaced the file.
- **Quieter Files (Mac).** Files skips temp folders, and only starts a sync for changes that can alter what it finds.

## When you update on Windows or Linux

- The overnight review starts running, as on the Mac. It reads yesterday only and waits for mains power.
- Think and Agent Mode refuse plain `http://` to any server that isn't this computer, including your network and Tailscale. Move those to HTTPS.
- Ask chats are now encrypted. Without a credential store, new chats stay in memory and a banner says so.
- Coding-agent sessions need you to opt in, even if a saved setting says they're on.

Windows and Linux remain in alpha. This release was tested on an automated Windows desktop, not yet by hand, and many new translations are machine-assisted. The Windows app is not yet code-signed.
