## What’s new

- **LokalBot for Windows and Linux (alpha).** A native app for Windows 10 and 11 (x64) and Linux (x86_64) with the same pages and library format as the Mac app, so a library moves between computers. It records meetings without a bot, transcribes and summarizes them on your computer, and has Ask, search, day memory, opt-in screen context, dictation, autocomplete, calendar feeds, Agent Mode, the read-only CLI and MCP server, and signed updates that install only when you choose. Download the Windows installer below (it installs for your user, with no administrator rights; a portable zip is there too), or for Linux the `.tar.gz` (run `./install.sh`), the `.deb` for Debian and Ubuntu, the `.rpm` for Fedora and openSUSE, or the Arch package. It’s an alpha: the Windows build isn’t code-signed yet, so SmartScreen asks before the first launch, some features depend on your Linux desktop, and a few Mac features aren’t there yet. See the [system requirements](https://www.lokalbot.com/system-requirements).
- **Ask remembers you (Mac).** Say “Remember …” in Ask or Quick Recall, or add items in Settings → Day Memory → About you, and Ask uses them when they fit the question. LokalBot can also learn facts and goals from your own words in meetings, and you review anything less certain. Agents can read only the items you choose to share, under their own permission, and get a short start-of-session briefing.
- **Rewrite what you selected (Mac).** Turn on selection actions, select text in any app, and press ⌃⇧ W to fix the grammar, shorten, translate, or summarize it, or draft a reply grounded in your meetings. Ask also shows matching app commands, such as Record now.
- **Import recordings.** Drop an audio or video file on Meetings, or choose Recording → Import Recording…, and it becomes a meeting with a transcript, speakers, a summary, and actions.
- **A note for every meeting in Obsidian or Logseq (Mac).** Settings → Recording → Meeting note export writes one Markdown note per meeting, including past ones, and leaves notes you edit alone.
- **24 interface languages.** The app is now available in Simplified and Traditional Chinese, Hindi, Spanish, Arabic, French, Portuguese, Russian, German, Japanese, Korean, Italian, Serbian, and more. Arabic and Urdu use a right-to-left layout.
- **Works in mainland China (Mac).** Tencent Meeting, VooV, Feishu, Lark, DingTalk, and WeCom calls are recognized; Chinese, Japanese, and Korean keyword search matches anywhere in a phrase; and models can download from HF-Mirror or ModelScope.
- **Timeline leads with what needs action** and folds the rest. On Mac, day digest tasks are also named by the work rather than the first request or folder.
- **Agents can set LokalBot up from the terminal, with your approval (Mac).** `lokalbot-cli setup`, `config`, `status`, and `doctor` let Claude Code or Codex install and configure LokalBot, while anything that widens what it captures or sends waits for you. `lokalbot-cli ask` and `reply` power new Ask LokalBot and Draft Reply commands for Raycast.

## Fixes

- Ask verifies each citation separately when several meetings are grouped together.
- The Qwen word-timing aligner’s memory stays bounded on long meetings.
- MAI-Transcribe-2 and the OpenRouter speech models use the server’s word times instead of the local aligner.
- Agent Mode checks file reads against the file it actually opens.
