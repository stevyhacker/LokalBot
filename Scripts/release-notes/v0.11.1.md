## What’s new

- **Try a sample meeting.** Before you record anything, **Try a sample meeting** on Meetings or in Today’s Get started list imports a short made-up call. LokalBot transcribes it and writes its notes on your computer. Then ask the suggested question and open the passage the answer cites. The sample is spoken in English, German, Chinese, or Serbian, following your interface language. It stays out of Today, day memory, people, projects, and actions, and **Remove sample** deletes it. If a model it needs is missing, LokalBot shows which and downloads nothing until you choose to.
- **The Timeline in your language.** The Timeline’s newer labels, such as Needs Attention, Update Digest, and Work Summary, are now translated into all 24 interface languages.
- **Updates for package installs (Linux).** When a package manager installed LokalBot, the update notice now says how to update: with your package manager when it came from a package repository, or with the command that installs the release’s new `.deb`, `.rpm`, or Arch package.

## Fixes

- **Windows:** after LokalBot updates itself, Settings → Apps → Installed apps shows the new version.
- **Hyprland and Sway:** the first-run welcome window floats over the main window instead of splitting the screen.
- **Windows and Linux:** the CLI and MCP server no longer point agents at About you settings that exist only in the Mac app.
- `lokalbot --version` and `lokalbot-cli --version` work on Windows and Linux, and `lokalbot-cli --version` on Mac.
- The Windows and Linux downloads include the license texts for every bundled library, font, icon set, and model. The Arch package depends on `libgcc`, `libstdc++`, and `hicolor-icon-theme` instead of `gcc-libs`.
