## What’s new

- **Agent Mode as a desktop workspace.** Agent tasks live in a persistent workspace with a composer, queued controls, results inspector, and conversation history that survives across selections. Approval mode is remembered, task context is preserved, and stopping waits for settlement with approvals cancelled cleanly.
- **Smarter Meet speaker suggestions.** Speaker labeling prefers verified participants, offers editable name-like email suggestions, keeps microphone and system tracks separate, and stays responsive while transcripts stream in.
- **Updated speech, Agent, and Sparkle dependencies.** Refreshed speech, Agent Mode runtime, and Sparkle packages plus a rebuilt llama.cpp bundle, with smoke coverage for the native speech cores.
- **More responsive transcript views.** Markdown rendering reuses bounded caches and meeting document snapshots read in batches, so long meetings stay smooth while loading.

**Full changelog:** https://github.com/stevyhacker/lokalbot/compare/v0.8.4...v0.8.5
