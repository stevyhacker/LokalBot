# LokalBot: Local Desktop AI Leaderboard

Extracted, sourced benchmark numbers across 7 desktop AI workloads and 20
reproducible suites behind [LokalBot](https://github.com/stevyhacker/lokalbot):
v0.14.0 Apache-2.0 fine-tunes, speech-to-text vs. cloud APIs, speaker
diarization, memory recall vs. restraint, inline autocomplete, hybrid QMSum
retrieval, structured extraction, OCR, and local TTS. Every figure links back
to its source report or Hugging Face model card; nothing is estimated.

- Hardware & RAM calculator: https://www.lokalbot.com/hardware
