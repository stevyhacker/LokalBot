# LokalBot: One Decision

Use the [shared video instructions](../AGENTS.md). Resume from `SPEC.md`, `STORYLINES.md` and `REVIEW.md`; `README.md` says how the footage was made and what is real.

- The scenes are `compositions/*.html`, edited by hand. `index.html` is generated by `build.py`, which holds the scene order and lengths and every voice line and effect: change those there, never in `index.html`. `compositions/agent.html` holds the recorded terminal session's lines: change its text only from a new recording (`film/agent/record.py`).
- Footage is real: `film/film.sh` films the takes in the UI Test Host and `film/cut.sh` cuts them into `assets/footage/`. Never redraw product UI or suggestion text. The highlighter rectangles are placed from each take's frame, so a new take needs its positions measured again.
- Filming opens windows and drives the pointer and keyboard: ask the user first, check the screen is unlocked, have them switch the installed LokalBot's Autocomplete off for the autocomplete take, and never run it while they are working.
- The voice is ElevenLabs (`voice/tts.py`, key `ELEVEN_LABS_API_KEY` from the main checkout's `.env`, never written to disk). It is a paid call: voice only the lines whose text changed, and check each take with a local transcription.
- HyperFrames is pinned to 0.8.150 in `package.json`. `python3 build.py`, `npm run check`, render with `--video-frame-format png`, then `./master.sh` for the loudness.
