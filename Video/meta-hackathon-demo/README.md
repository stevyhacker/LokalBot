# From meeting to done — Meta hackathon demo film

A three-minute film for the Meta Global AI Developer Hackathon entry, cut from the CI film of the hackathon UI test. The render lands in `renders/` (gitignored, like the footage, voices, music and fonts).

## What is real

- Every shot of the app is the CI film unchanged: `HackathonFilmUITests` driving LokalBot's UI-test host on a GitHub-hosted Mac, with Muse Spark 1.3 and Muse Wonder 1.0 answering live through the Meta Model API. The run id is in `production/anchors.json` and `assets/footage/run-id.txt`.
- The call is a stand-in window in the UI-test host (`LokalBot/Views/FilmCallWindow.swift`), and its words are the test's script: the runner has no meeting audio. Muse Voice Transcribe is named in the narration because it is the feature, but the film's transcript comes from the script. The film says so on screen and on the end card.
- The radar items, screen answer, live answers, their sources, and the Follow-through drafts are what Muse returned in that run. Slowed footage only stretches moments where the UI waits. App footage at 1.25× or faster shows a speed badge; the scripted call's typing is retimed to the voices. The first live answer plays in real time.
- The voices are synthetic: ElevenLabs `eleven_v4`, the narration and Stevan's lines in the author's own voice clone, Ana's lines in the "Ana" voice (`tts.py`, alignment in `production/voice-generation.json`). Each take was transcribed with faster-whisper base.en (`check_voice.py`, `production/voice-asr.json`). The music bed is generated by `compose_bed.py`.

## Rebuild

```sh
bash fetch_assets.sh <meta-hackathon-film run id>   # footage + fonts
# find the take's moments (production/ocr, tesseract) and update production/anchors.json
python3 plan.py      # edit.json: beats on the output timeline, rates fitted to the voice lines
python3 mix.py       # assets/sound/final-mix.wav, about -16 LUFS
python3 build.py     # index.html
npx --yes hyperframes@0.8.150 check
npx --yes hyperframes@0.8.150 render --fps 30 --quality delivery --workers 4 --strict --output renders/meta-hackathon-demo.mp4
```

Voices: edit `narration.json`, load `ELEVEN_LABS_API_KEY` from the main checkout's `.env`, run `python3 tts.py --only <ids>`, check with `uv run --no-project --with faster-whisper --with numpy python check_voice.py`, and name a different seed in `plan.py`'s `TAKES` when one reads better.
