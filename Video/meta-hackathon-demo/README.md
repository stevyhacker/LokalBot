# From meeting to done — Meta hackathon demo film

A three-minute film for the Meta Global AI Developer Hackathon entry, cut from the CI film of the hackathon UI test. The render lands in `renders/` (gitignored, like the footage, voices, music and fonts).

## What is real

- Every shot of the app is the CI film unchanged: `HackathonFilmUITests` driving LokalBot's UI-test host on a GitHub-hosted Mac, with Muse Spark 1.3 and Muse Wonder 1.0 answering live through the Meta Model API. The hosted Mac's own screen isn't Retina, so the workflow gave it a 1600×1000 point virtual HiDPI display (`Scripts/film/virtual-display.m`) and filmed its 3200×2000 pixels (`Scripts/film/capture.py`), at about 2 frames a second. That workflow (`.github/workflows/meta-hackathon-film.yml`) and `Scripts/film/` were removed after the hackathon; they are in the repository's history up to commit `648005e`. The run id is in `production/anchors.json` and `assets/footage/run-id.txt`.
- One shot comes from another run of the same test: the press of Start Radar. The screen capture stalled for about ten seconds there in the take this film uses, so the first attempt of run 41453444742 fills it, appended to `film.mp4` after the take as `assets/footage/start-radar-press.mp4` (`press` in `production/anchors-manual.json`).
- The call is a stand-in window in the UI-test host (`LokalBot/Views/LiveRadar/FilmCallWindow.swift`), and its words are the test's script: the runner has no meeting audio. Muse Voice Transcribe is named in the narration because it is the feature, but the film's transcript comes from the script. The end card says so.
- The radar items, screen answer, live answers, their sources, and the Follow-through drafts are what Muse returned in that run. Slowed footage only stretches moments where the UI waits. App footage at 1.25× or faster shows a speed badge; the scripted call's typing is retimed to the voices.
- The capture shows no pointer, so a yellow ring drawn over the footage marks three clicks the test makes: Start Radar, and approving the email and the invitation. Follow-through ran on "Decide free tier limit with Ana", the action this take's test reached, so the film voices that exchange. Stevan's line is the script's, "with Ana" included, because the radar's card quotes it.
- In this take the test host doesn't launch Mail or Calendar (`AppFollowThrough.open` returns success under the UI-test transport), so the film shows "Opened in Mail" with no window. An on-screen label and the end card say so.
- The numbers on the model cards are from `HACKATHON.md`'s results, measured outside this film.
- The seconds where the capture stalled during Ana's journalist question are cut, and that line's caption is the film's own.
- The voices are synthetic: ElevenLabs `eleven_v4`, the narration and Stevan's lines in the author's own voice clone, Ana's lines in the "Ana" voice (`tts.py`, alignment in `production/voice-generation.json`). Each take was transcribed with faster-whisper base.en (`check_voice.py`, `production/voice-asr.json`). The music bed is generated by `compose_bed.py`.

The camera is per-frame transforms and a clip path, zooming around the one film point its two poses share, rendered at 60 fps. Layout properties snap to whole pixels, and a 1.3 s move at 30 fps stepped visibly. The transforms sit on a wrapper around the `<video>`: on the element itself, the renderer only applied them when a new video frame was shown, so zooms over slowed footage stepped at 60 × the footage rate. The board dissolves across its scroll hops, which are the gaps between captures.

## Rebuild

The footage is not in the repository. `fetch_assets.sh` downloads it from a run of the removed film workflow, whose artifacts GitHub keeps for 30 days after the run; after that, a rebuild needs a copy of `assets/footage/film.mp4` from an earlier checkout.

```sh
bash fetch_assets.sh <meta-hackathon-film run id>   # footage + fonts; append the Start Radar clip if the take's capture stalled there
python3 anchors.py   # production/anchors.json: the take's moments, by OCR; set any it misses in production/anchors-manual.json
python3 plan.py      # edit.json: beats on the output timeline, rates fitted to the voice lines
python3 mix.py       # assets/sound/final-mix.wav, about -16 LUFS
python3 build.py     # index.html
npx --yes hyperframes@0.8.150 check
npx --yes hyperframes@0.8.150 render --fps 60 --quality delivery --workers 4 --strict --output renders/meta-hackathon-demo.mp4
```

Voices: edit `narration.json`, load `ELEVEN_LABS_API_KEY` from the main checkout's `.env`, run `python3 tts.py --only <ids>`, check with `uv run --no-project --with faster-whisper --with numpy python check_voice.py`, and name a different seed in `plan.py`'s `TAKES` when one reads better.
