# Desktop port privacy contract

This is the Linux/Windows Rust implementation. The existing macOS contract remains in [../PRIVACY.md](../PRIVACY.md). The following describes actual port behavior, including differences.

An ordinary launch stores an empty library locally. Synthetic examples are created only by the explicit seed command, and the UI labels that library. There is no analytics, telemetry or background model download. Activity metadata defaults on; visible screen text, pixels, remote audio, external meeting access, external screen access and Agent Mode are independent settings and default off.

SQLite and audio reside in the current user's data directory. Unix library directories are mode 0700; atomic files are private. On Windows the library inherits the user's directory ACL. The database/text/audio are not encrypted at rest. Opt-in screen pixels use authenticated AES-256-GCM with a private per-library key file; this protects the payload, not against another process already running as that user. User-held exports are outside retention. Credentials entered through Settings use the OS credential store (Secret Service plus Linux keyring on Linux, Windows Credential Manager on Windows). Environment credentials stay in the process and are not written to the library.

The capture helper reads a bounded visible accessibility tree, not hidden document values, selections, help attributes or clipboard contents. Unknown focus, missing focused-field identity, secure fields, exclusions or a timeout refuse screen capture. App/window/focused-field identity and current settings must match before and after capture. Commit holds a SQLite writer lock while checking consent revision. Sensitive strings and email addresses are redacted before persistence; detected sensitive text suppresses pixels. Excluded activity records retain time under “Private” without window title. Browser domain exclusions fail closed when the helper cannot establish the domain. Incognito/private windows do not receive a special inferred grant.

Unsaved screen text and pixels expire after the configured retention period (14 days by default); saved moments remain until unsaved/deleted. Old activity titles expire while app duration stays. Meeting audio/text, notes, conversations, agent tasks and generation usage remain until explicit deletion/clear. Source deletion/correction removes FTS entries and invalidates generated daily digests; generation validates original evidence again before saving. Retention runs on launch, health checks and the capture worker. Retention removes app-owned records/files, not forensic copies in filesystem snapshots or SQLite free pages.

Remote inference requires approval of the exact HTTPS origin (HTTP is accepted only for loopback). Redirects are rejected. OpenRouter credentials are restricted to `https://openrouter.ai`; compatible servers do not receive them. Approved models receive redacted retrieved passages, relevant enabled screen text, user questions, and daily digest evidence; no pixels, pixel file paths or raw audio are included in text requests. OpenRouter requests use `provider.data_collection=deny` and require provider parameter support unless the user explicitly selects account-policy routing. Failed requests do not change this choice. In-flight result writes are discarded if the consent revision or their sources changed. Revocation cannot retract data already sent to a provider.

Remote audio is a separate opt-in. The transcription API cannot enforce private-only provider routing, so the port refuses remote audio unless account-policy routing is explicitly selected. Local Whisper receives audio through local files and runs without a GPU. Selecting a local compatible endpoint means that endpoint controls its own model/runtime and data handling.

The CLI/MCP read surface separately checks current meeting-library and time-scoped screen-memory grants; screen results never contain pixels or their paths. MCP is read-only stdio, with no listening server. Import/edit/process/export/delete/configure are explicit owner commands, not MCP tools. Imported IDs are remapped and external media paths are discarded. Importing a transcript is an intentional write into this port's independent library.

Agent Mode has separate opt-in and an explicit workspace outside the library. Planning sends only the user's task text; library attachments are not inferred. Each direct executable proposal needs a manual approval with complete arguments. Approved commands get a small environment allowlist, no provider credentials or library-root variable, a 30-second bound and bounded redacted output. They run as the user and can access files/network through their own code; this is not a sandbox or a promise that all command destinations obey inference-origin consent.

Capture pixels travel through bounded process pipes into memory and are encrypted before any app-owned pixel file is written. Startup removes orphan encrypted files and legacy interrupted plaintext captures. Unchanged windows are stored at most once per five minutes; contiguous identical activity samples share an interval. Retention uses complete indexed range queries independent of display limits. Settings saves compare revisions and reject stale copies instead of restoring revoked grants. Loopback inference bypasses system proxies.

Recording recovery isolates failures per meeting and retains damaged checkpoints for explicit repair. Verified finalized recordings discard redundant pieces only after saving their metadata. Re-transcription preserves existing notes, reviewed actions and the exact old passages they cite. Opt-in remote audio is streamed into bounded WAV parts below the upload limit; current consent is checked before and after each request. FFmpeg has a ten-minute bound, CPU Whisper a two-hour bound. Bounded helpers terminate their process group on Unix or their inherited job on Windows; this bounds ordinary descendants and is not a security sandbox for arbitrary code.

The explicit model bootstrap accesses GitHub for pinned whisper.cpp source and Hugging Face for a pinned model, verifying its SHA-256. Those hosts and optional inference providers receive ordinary network metadata. Public CI and live validation use fictional fixtures only. No private meetings or screen content are sent during those checks.
