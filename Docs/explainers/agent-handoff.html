Hand off work to an agent

Two ways to give an agent a task with its context already attached: your actions from a meeting, or whatever is in the window in front of you. Both are off until you turn them on, and nothing reaches an agent until you send it.

A meeting from the last day is summarized, with its action items.

Turn it on
WhatWhere
Meeting actions, after each summarySettings → Meetings → Processing → Hand off my actions to Agent Mode after each summary
Meeting actions, on requestA meeting's More menu → Hand off my actions to Agent Mode. No setting needed.
Start without a clickSettings → Meetings → Processing → Start handoffs automatically. Agent Mode's approval mode still decides what an agent may do without asking.
Any windowSettings → Ask → Enable the Hand off shortcut. The shortcut is ⌃⇧H unless you change it.
What it reads, keeps and sends
  • A window: all of its Accessibility text, including text scrolled out of view, the selected text, and a screenshot when Screen Recording is allowed. Excluded apps and sites and windows with a password field aren't read. Credentials, card numbers and IBANs are redacted, and the screenshot is dropped when anything was redacted.
  • Nothing goes into screen memory, and Hand off works with screen memory off.
  • The window's text goes to your Think model to write the brief: on this Mac if that model is local, or to the server you approved for Think.
  • Each window handoff is saved as a folder under handoffs/ in your library, readable only by your user, and deleted after 7 days.
  • A meeting: the attached meeting's summary is read and sent to Agent Mode's model only when the task is sent.
  • The prompt tells the agent not to send, post, publish, buy or delete anything. Full details are in PRIVACY.md.
Limits
  • Mac only. Claude Code and Codex are offered only when they're installed.
  • Only meetings from the last day hand off automatically, so importing old recordings doesn't fill Agent Mode.
  • New in 0.12.3. It is covered by automated tests, but has had little use in real work yet.
